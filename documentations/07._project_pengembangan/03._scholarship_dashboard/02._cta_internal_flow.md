# CTA Internal Beasiswa — Alur & Spesifikasi

## Ringkasan
- CTA “Daftar Sekarang” pada halaman detail beasiswa menggunakan formulir internal.
- Wajib login sebelum mengirim aplikasi.
- Data tersimpan ke `scholarship_applicants` dengan status awal `pending`.
- Admin memproses di tab Applicants pada masing-masing beasiswa.

## Status Beasiswa (Stabilisasi)
- Public “open” = `active`. Hanya beasiswa berstatus `active` yang:
  - Muncul di listing publik.
  - Dapat ditampilkan detailnya untuk publik.
  - Memunculkan CTA “Daftar Sekarang” dan menampilkan Form Pendaftaran.
- `closed` berarti pendaftaran ditutup; CTA nonaktif dan form disembunyikan.
- `pending` dan `rejected` adalah status internal admin, tidak muncul di publik.
- Editor dapat melihat detail beasiswa non-`active` untuk keperluan review.

## Endpoint Backend
- Method: POST  
  Path: `/beasiswa/{scholarship:slug}/apply`  
  Name: `scholarships.apply`  
  Middleware: `auth`, `throttle:10,1`

### Validasi
- `essay`: required, string, min 30 karakter
- `cv`: required, file, mimes: pdf, max 2MB
- Unik: kombinasi `(scholarship_id, user_id)` (dilindungi index unik DB dan dicek aplikasi)

### Penyimpanan
- CV disimpan ke `storage/app/public/scholarship_cvs`
- Path relatif disimpan ke kolom `cv_path`
- Status awal: `pending`

## Integrasi Frontend (Inertia React)
- Lokasi: `resources/js/Pages/Scholarship/Show.tsx`
- Tombol “Daftar Sekarang”:
  - Muncul hanya ketika status beasiswa `active`.
  - Jika belum login → redirect ke `/login` (intended back).
  - Jika login → membuka form pendaftaran (essay + upload CV).
- Submit:
  - `Inertia.post(route('scholarships.apply', scholarship.slug), { forceFormData: true })`
  - Sukses → reset form dan tampilkan pesan berhasil

## Alasan Arsitektur
- Data terpusat untuk 5–10 tahun ke depan
- Mendukung notifikasi, analitik, histori pelamar, dan integrasi RBAC Program

## Catatan
- Status publik beasiswa: gunakan `active` untuk tampil di listing dan dapat didaftar
- Degree filter dinormalisasi (`S1/S2/S3` → `s1/s2/s3`)
