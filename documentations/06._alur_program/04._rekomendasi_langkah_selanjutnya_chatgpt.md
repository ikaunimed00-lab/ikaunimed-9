# 🏢 IKA UNIMED = Sebuah Gedung Besar

Di dalam gedung itu ada:

* Ruang Donasi
* Ruang Beasiswa
* Ruang Karir
* Ruang Learning
* Dan nanti bisa tambah ruang baru lagi

Sekarang masalahnya:

Gedung ini:

* Bisa buka-tutup ruang tertentu
* Setiap ruang punya admin sendiri
* Pimpinan ingin lihat laporan semua ruang
* Ruang tampil di website dan juga di dashboard

Jadi kita tidak sedang membuat “website biasa”.

Kita sedang membuat:

> Sistem Gedung dengan banyak ruang yang bisa diatur.

---

# 🧱 Fondasi Paling Penting (Supaya Tidak Amburadul)

Sebelum bikin ruang-ruang itu, kita harus bikin:

## 1️⃣ Buku Daftar Ruangan (Program Registry)

Ini seperti daftar:

| Nama Program | Status | Tampil dimana      |
| ------------ | ------ | ------------------ |
| Donasi       | Aktif  | Public & Dashboard |
| Beasiswa     | Pause  | Dashboard saja     |

Dengan ini:

* Program bisa dihentikan sementara
* Bisa ditampilkan atau disembunyikan
* Bisa tambah program baru tanpa bongkar sistem

Ini WAJIB.

---

## 2️⃣ Kartu Akses Tiap Ruangan

Karena:

* Admin Donasi belum tentu admin Beasiswa
* Admin Beasiswa belum tentu admin Karir

Jadi kita buat sistem:

“Si A adalah Admin di Donasi”
“Si A hanya User biasa di Learning”

Ini supaya:

* Tidak semua admin bisa masuk semua program
* Data lebih aman
* Tidak berantakan

---

## 3️⃣ Status Program (Aktif / Pause / Arsip)

Program bisa:

### ✅ Aktif

Normal berjalan.

### ⏸ Pause

Masih terlihat, tapi tidak bisa dipakai.

### 📦 Arsip

Tidak tampil ke publik, tapi datanya tetap ada.

Jangan pernah hapus program.
Organisasi butuh histori.

# 🔐 Apakah Role Lama Aman?

Ya, aman.

Karena:

Role lama = level global
Program role baru = level per program

Contoh nanti:

| User | Role Global   | Role Program              |
| ---- | ------------- | ------------------------- |
| A    | Super Admin   | Semua program             |
| B    | Editor        | Admin Donasi              |
| C    | Writer Cabang | Tidak punya akses program |

Jadi role lama tetap hidup.

Kita hanya menambah layer baru.

# 🧩 Apakah Perlu Ubah Struktur Role Lama?

Tidak perlu.

Yang kita lakukan hanya:

Menambahkan kemampuan baru seperti:

```
$user->hasProgramRole($program, 'admin')
```

Tanpa mengganggu:

```
$user->hasRole('editor')
```

Dua sistem bisa berjalan berdampingan.
