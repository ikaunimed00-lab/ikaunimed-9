## Tujuan

> *Mengaktifkan iklan nyata di production-grade tanpa menyentuh kode — hanya lewat tabel `site_settings` yang juga dapat diedit dari Filament UI grup `Ads`.*

Strategi yang dipilih (konfirmasi user di sesi):

- **Skip AdSense untuk sekarang** (situs masih menunggu approval Google AdSense; baru punya `ca-pub-3622809427438663`, belum punya Ad Unit Slot IDs).
- **Aktifkan Adsterra penuh** karena snippet sudah lengkap di [`14._adsense/02._adsterra.md`](../14._adsense/02._adsterra.md) dan bisa diaktifkan tanpa approval lebih lanjut.
- **Bersihkan placeholder** AdSense (client_id + 5 slot id) supaya saat user kelak flip `ads_enabled=true` tanpa isi slot, **tidak ada `<ins data-ad-slot="...">` palsu** yang bocor (anti-regresi terhadap kebijakan Item 5).

Kalau Google AdSense crawler kebetulan datang sebelum eksekusi ini, situs bisa kena flag policy violation.

## Cara Mengubah Lewat Filament UI (Untuk User di Masa Depan)

Login admin → **Site Settings** → filter **group = "ads"**. 10 record akan terlihat:

| Label | Saat Ini | Yang Bisa Diubah |
|-------|----------|------------------|
| Enable Ads | `false` | Set `true` saat AdSense approved + slot terisi |
| Primary Ads Provider | `adsense` | Biarkan `adsense` (tidak dipakai saat `Enable Ads` off) |
| AdSense Client ID | (kosong) | Isi `ca-pub-3622809427438663` saat AdSense approved |
| AdSense Banner Slot | (kosong) | Isi 10-digit Ad Unit ID dari AdSense console |
| AdSense Sidebar Slot 1 | (kosong) | idem |
| AdSense Sidebar Slot 2 | (kosong) | idem |
| AdSense Inline Article Slot | (kosong) | idem |
| AdSense List Item Slot | (kosong) | idem |
| Enable Adsterra | `true` | Set `false` jika ingin matikan Adsterra |
| Adsterra Body Snippet | `<script ...></script>...` | Update jika Adsterra ganti URL invoke.js |

> **Catatan keamanan:** field `Adsterra Body Snippet` di-render via `{!! ... !!}` (HTML mentah) — hanya admin terotorisasi yang boleh edit. Cegah XSS dengan tidak menempel HTML dari sumber tidak terpercaya. Saat ini hanya snippet resmi Adsterra yang ada di sana.

## Phase B — Saat AdSense Approved Nanti

Tinggal isi 6 field via Filament UI (atau tinker), tanpa sentuh kode:

```php
ads_enabled                  = true
adsense_client_id            = 'ca-pub-3622809427438663'
adsense_slot_banner          = '<10-digit dari AdSense console: Ad Unit "Banner 970x90">'
adsense_slot_sidebar_1       = '<10-digit dari AdSense console: Ad Unit "Sidebar 300x250">'
adsense_slot_sidebar_2       = '<10-digit dari AdSense console: Ad Unit "Sidebar 300x600">'
adsense_slot_inline_article  = '<10-digit dari AdSense console: Ad Unit "In-Article">'
adsense_slot_list_item       = '<10-digit dari AdSense console: Ad Unit "In-Feed">'
```

Setelah save, otomatis tanpa redeploy:

- `<script ...adsbygoogle.js?client=ca-pub-3622809427438663>` muncul di `<head>`.
- 5 komponen Ad* di `News/Index.tsx` & `News/Show.tsx` mulai render `<ins class="adsbygoogle" data-ad-slot="...">` sesuai slot.
- Adsterra **tetap aktif paralel** (kedua provider bisa hidup bersamaan; tidak ada konflik di kode karena AdSense via React `<ins>` sementara Adsterra via raw HTML di akhir `<body>`).

> ⚠️ **Best practice AdSense:** sebaiknya jalankan AdSense **setelah** Adsterra ter-validasi tidak melanggar kebijakan AdSense (Google ketat soal "co-existence with other ad networks"). Cek AdSense Program Policies dulu sebelum Phase B.

## Catatan Tambahan — Komponen `AdsenseUnit.tsx`

Saat ini `<ins class="adsbygoogle">` yang dirender hanya men-set `data-ad-slot`, **bukan `data-ad-client`**. Ini bekerja karena AdSense mode "auto" akan meng-infer `data-ad-client` dari URL `<script>?client=...`. Tapi best practice Google **menganjurkan** setiap `<ins>` punya `data-ad-client` eksplisit. Saat Phase B nanti, pertimbangkan menambahkan prop `client` ke `AdsenseUnit` & wiring `ads.client_id` ke setiap pemakaian. Detail bisa dikerjakan di Item 6 atau iterasi terpisah — **belum mengganggu** karena Phase B belum aktif.
