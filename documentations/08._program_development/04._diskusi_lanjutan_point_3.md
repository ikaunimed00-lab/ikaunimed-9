- Dokumen menegaskan prioritas: bangun Program “Karir & Jejaring Profesional” bertahap.
- Fondasi paling tepat: Direktori Alumni Profesional, lalu “Lowongan dari Alumni”, kemudian fitur jejaring lanjutan.

**Posisi Sistem Saat Ini**

- Sudah stabil:
  - Beasiswa dan Kabar Alumni memakai pola pending → review → published, approval terpusat di Filament.
  - Profil alumni sudah ada dan menjadi pusat data pengguna [AlumniProfileController](file:///D:/Documents/WEBSITE/ikaunimed-9.or.id/app/Http/Controllers/AlumniProfileController.php).

- Implikasi: kita sudah punya pondasi untuk dua arah tadi (direktori dan lowongan), tinggal standarisasi profil dan mengekspose versi publiknya.

**Rekomendasi Modul Berikutnya**

- Fokus: Direktori Alumni Profesional (sebagai pondasi “Karir & Jejaring”).
- Alur bertahap:
  - Tahap 0: Profil Alumni (sudah ada).
  - Tahap 1: Standarisasi field profesional + indikator kelengkapan profil.
  - Tahap 2: Halaman Direktori Publik dengan filter dasar.
  - Tahap 3: Integrasi ke Lowongan (tampilkan profil pemberi lowongan).
  - Tahap 4: Fitur jejaring lanjutan (rekomendasi koneksi, highlight, dsb.).

**Desain Konseptual**

- Standarisasi Profil (di dashboard profil, bukan di modul lain):
  - Wajib: bidang pekerjaan, posisi saat ini, perusahaan, kota domisili/kerja.
  - Opsional: LinkedIn/URL profesional, ringkas karier.
  - Privasi: boolean “Tampilkan ke Direktori Publik” (default non‑publik).
  - Indikator: is_profile_complete atau profile_completion_score untuk dipakai lintas modul (termasuk Beasiswa).
- Direktori Publik:
  - URL: /alumni.
  - Fitur awal: filter bidang, filter angkatan, pencarian nama; tampilkan hanya user public=true.
  - Kartu profil: nama, angkatan, prodi, posisi, perusahaan, kota, tautan ke profil publik.
- Integrasi Lowongan:
  - Postingan lowongan menampilkan identitas pemberi lowongan (nama alumni) yang dapat diklik ke profil publik.
  - Profil publik menampilkan daftar lowongan yang pernah diposting alumni tersebut (opsional).
- Moderasi & Akses:
  - Pengelolaan status tetap via Filament untuk konten; profil tidak perlu moderasi, cukup kontrol visibilitas (public flag) dan validasi server.
  - RBAC tidak berubah: Subscriber mengisi profil; Editor/Admin dapat mengoreksi data saat diperlukan melalui panel admin pengguna [UserResource](file:///D:/Documents/WEBSITE/ikaunimed-9.or.id/app/Filament/Resources/Users/UserResource.php).

**Integrasi Dengan Modul yang Ada**

- Beasiswa:
  - Validasi kelengkapan profil saat apply memakai is_profile_complete/profile_completion_score, bukan menambah field ke beasiswa. Ini menjaga kebersihan domain beasiswa.
- Kabar Alumni dan Lowongan:
  - Tidak berubah secara arsitektur; hanya memperkaya kredibilitas lewat tautan ke profil publik alumni pemberi info/lowongan.

**Risiko & Mitigasi**

- Data sensitif di publik:
  - Mitigasi: default public=false, granularitas data publik vs privat (contoh: email/WA tetap privat).
- Fragmentasi data pekerjaan:
  - Mitigasi: enum “bidang pekerjaan” (contoh: Pendidikan, Keuangan, Teknologi, Kesehatan, dll.) dengan opsi “lainnya” + teks bebas.
- Kesesuaian data lama:
  - Mitigasi: migrasi ringan + fallback aman; tidak wajib publik untuk profil lama.

**Usulan Field (Draft, tanpa implementasi)**

- Wajib: bidang_pekerjaan (enum), posisi_saat_ini (string), perusahaan (string), kota (string), angkatan (tahun), prodi (string).
- Opsional: linkedin_url, ringkasan_karier (short bio).
- Privasi: public_profile (boolean).
- Indikator: is_profile_complete (boolean) atau profile_completion_score (0–100).

**Langkah Berikutnya (Diskusi Dulu, Tanpa Eksekusi)**

- Validasi daftar enum bidang pekerjaan yang relevan untuk IKA UNIMED.
- Tentukan skema “profil lengkap”: ambang minimal yang dianggap layak untuk:
  - tampil di direktori publik,
  - melamar beasiswa (opsional threshold lebih tinggi).
- Putuskan tampilan direktori awal: kartu sederhana vs tabel, serta filter yang ditampilkan default.
- Setelah disepakati, baru kita siapkan blueprint implementasi (migrasi field profil, controller + halaman /alumni, dan integrasi ringan ke lowongan).
