# 🎯 Strategi yang Benar untuk Menyamakan Vibe ikaunimed-8

Kita pisahkan jadi 3 layer:

1. 🎨 Warna (Theme Layer)
2. 🏷 Branding (Logo & Brand Text)
3. 🌑 Sidebar Gradient (Custom CSS Injection)

---

# ✅ 1️⃣ Ganti Warna Primary (Emerald/Teal)

Buka:

```
app/Providers/Filament/AdminPanelProvider.php
```

Ubah bagian:

```php
->colors([
    'primary' => Color::Amber,
])
```

Menjadi:

```php
use Filament\Support\Colors\Color;

->colors([
    'primary' => Color::Emerald,
    'gray' => Color::Slate,
])
```

💡 Ini akan langsung mengubah:

* Button
* Badge
* Active state
* Toggle
* Link accent
* Form focus ring

Tanpa merusak komponen.

---

# ✅ 2️⃣ Branding Logo + Nama IKA UNIMED

Masih di `AdminPanelProvider.php`, tambahkan:

```php
->brandLogo(asset('images/favicon_ikaunimed.png'))
->brandLogoHeight('2.5rem')
->brandName('IKA UNIMED')
```

Kalau mau lebih premium:

```php
->brandName('IKA UNIMED Portal Admin')
```

# 🔥 3️⃣ Membuat Sidebar Gradient seperti Portal Alumni

Filament tidak default gradient sidebar.

Cara aman:

Buat file baru:

```
resources/css/filament/admin.css
```

Isi:

```css
.fi-sidebar {
    background: linear-gradient(
        to bottom,
        #1F2937,
        #111827,
        #0F172A
    ) !important;
}

.fi-sidebar-item-active {
    background: linear-gradient(
        to right,
        rgba(16, 185, 129, 0.2),
        rgba(20, 184, 166, 0.2)
    ) !important;
    border: 1px solid rgba(16, 185, 129, 0.3);
}
```

Lalu daftarkan di provider:

```php
->viteTheme('resources/css/filament/admin.css')
```

# 🎨 Kalau Mau Brand IKA(Orange) UNI(Teal) MED(Gold)

Filament default tidak bisa multi-color brand text.

Solusi advanced:

```php
->brandName(fn () => new HtmlString('
<span style="color:#FF7E00">IKA</span>
<span style="color:#00A69D">UNI</span>
<span style="color:#e9cf35">MED</span>
'))
```

🔥 Ini akan 100% mirip Portal Alumni.
