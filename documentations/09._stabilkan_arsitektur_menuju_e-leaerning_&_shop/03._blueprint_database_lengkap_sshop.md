# 1️⃣ CORE PRODUCT STRUCTURE

## 📦 1. products

Representasi utama produk.

```sql
id
name
slug (unique)
sku (unique, nullable)
description (longtext)
short_description (nullable)
price (decimal 12,2)
compare_price (nullable) 
cost_price (nullable)
stock (integer default 0)
track_stock (boolean default true)
is_digital (boolean default false)
weight (decimal 8,2 nullable)
status (draft/active/inactive)
vendor_id (nullable FK users)
category_id (nullable FK product_categories)
created_at
updated_at
```

### Kenapa field ini penting?

* `compare_price` → untuk diskon visual
* `cost_price` → analisis profit
* `track_stock` → produk unlimited (digital)
* `is_digital` → beda alur pengiriman
* `vendor_id` → siap marketplace
