a) Di method `show` saya tambahkan paket data `interest`:

```php
public function show(JobVacancy $vacancy)
{
    if ($vacancy->status !== 'active' && auth()->id() !== $vacancy->user_id && !auth()->user()?->isAdminOrEditor()) {
        abort(404);
    }

    $related = JobVacancy::where('status', 'active')
        ->where('id', '!=', $vacancy->id)
        ->where('type', $vacancy->type)
        ->limit(3)
        ->get();

    $user = auth()->user();

    $interest = [
        'is_interested' => false,
        'total' => $vacancy->interestedUsers()->count(),
    ];

    if ($user && $user->canAppearInDirectory()) {
        $interest['is_interested'] = $vacancy->interestedUsers()
            ->where('user_id', $user->id)
            ->exists();
    }

    return Inertia::render('JobVacancy/Show', [
        'vacancy' => $vacancy,
        'related' => $related,
        'interest' => $interest,
    ]);
}
```

Poin penting:

- Siapa pun yang mengakses lowongan tetap dicek seperti sebelumnya (active / pemilik / admin).
- `interest.total` selalu dihitung dari relasi `interestedUsers()`.
- `interest.is_interested` hanya `true` bila:
  - User login, dan
  - User memenuhi `canAppearInDirectory()` (profil profesional layak).
  - Dan punya entri di pivot.

b) Method baru `toggleInterest` untuk tombol “Saya tertarik”:

```php
public function toggleInterest(Request $request, JobVacancy $vacancy)
{
    $user = $request->user();

    if (! $user || ! $user->canAppearInDirectory()) {
        abort(403);
    }

    $alreadyInterested = $vacancy->interestedUsers()
        ->where('user_id', $user->id)
        ->exists();

    if ($alreadyInterested) {
        $vacancy->interestedUsers()->detach($user->id);
    } else {
        $vacancy->interestedUsers()->attach($user->id);
    }

    return redirect()->back();
}
```

Catatan:

- Hanya user login yang bisa akses (dijaga lagi di route).
- Hanya alumni dengan profil layak (`canAppearInDirectory()`) yang diperbolehkan menyatakan minat.
- Perilaku **toggle**:
  - Kalau sudah tertarik → detach (batalkan).
  - Kalau belum → attach (tandai tertarik).
