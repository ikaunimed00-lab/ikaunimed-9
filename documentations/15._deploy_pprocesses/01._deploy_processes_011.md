
## 12. Troubleshooting: Halaman Settings Error (Cannot read properties of undefined reading 'user')

Jika halaman `/settings/profile` atau halaman settings lainnya menampilkan error JavaScript `Cannot read properties of undefined (reading 'user')` setelah login, ini disebabkan oleh middleware Inertia yang belum terpasang pada route tersebut.

**Penyebab:**
File `routes/settings.php` dimuat secara manual di `bootstrap/app.php` tetapi tidak mewarisi grup middleware `web` standar yang berisi `HandleInertiaRequests`. Akibatnya, data `auth.user` tidak dikirim ke frontend React.

**Solusi:**
Tambahkan `HandleInertiaRequests::class` secara eksplisit pada grup middleware di `routes/settings.php`.

```php
// routes/settings.php
use App\Http\Middleware\HandleInertiaRequests; // Jangan lupa import

Route::middleware(['auth', HandleInertiaRequests::class])->group(function () {
    // ... route settings
});
```

**Deploy Fix:**
Setelah update file, jalankan perintah berikut di server untuk membersihkan cache route:
```bash
php artisan route:clear
php artisan optimize:clear
```
