# Rencana Migrasi Arsitektur Hybrid (Inertia + Filament)

Dokumen ini merinci langkah-langkah teknis untuk memindahkan fungsi administrasi internal ke Filament v3 dan merestrukturisasi frontend Inertia untuk Publik dan Alumni.

## 1. Fase Persiapan & Keamanan
- [ ] Instalasi Filament v3 melalui Composer.
- [ ] Konfigurasi `AdminPanelProvider` untuk menggunakan domain `/admin`.
- [ ] Integrasi `canAccessPanel()` pada [User.php](file:///app/Models/User.php) menggunakan role yang sudah ada (`admin`, `editor`, `writer`).
- [ ] Dokumentasi perubahan pada `02._migration_plan.md`.

## 2. Fase Migrasi Admin (Filament Resources)
Setiap resource akan dibuat untuk menggantikan fungsionalitas di `app/Http/Controllers/Admin`.

- **User Resource**: Manajemen user, penetapan role, dan organisasi.
- **Organization Resource**: Manajemen struktur organisasi (PP, DPW, DPC).
- **News Resource**: Pengelolaan berita dengan dukungan Media Library dan kategori.
- **Legalization Resource**: Workflow verifikasi ijazah.
- **Moderation Resource**: Untuk Scholarship, Job Vacancy, dan Partnership.

## 3. Fase Restrukturisasi Frontend (Inertia)
Pemindahan file di `resources/js/Pages/` untuk mengikuti standar arsitektur baru.

- **Folder `Public/`**: Memindahkan Index, News (Public), Info Pages, dll.
- **Folder `Alumni/`**: Memindahkan Dashboard khusus alumni, Profile Settings, dan Submission Legalization.
- **Folder `Auth/`**: Memindahkan Login, Register, Forgot Password.

## 4. Fase Pembersihan (Decommissioning)
Langkah terakhir untuk menghapus kode yang sudah tidak relevan.
- [ ] Penghapusan folder `app/Http/Controllers/Admin`.
- [ ] Penghapusan folder `resources/js/Pages/Dashboard/Admin`.
- [ ] Pembersihan route lama di `routes/web.php`.
- [ ] Update `RedirectAfterLogin` agar mengarah ke `/admin` untuk staff dan `/alumni/dashboard` untuk alumni.
