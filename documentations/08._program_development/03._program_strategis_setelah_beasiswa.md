# 1️⃣ Lowongan Pekerjaan (Job Vacancy)

Ini adalah **konten**.

Artinya:

* Satu postingan
* Ada judul
* Ada deskripsi
* Ada deadline
* Status pending → published
* Dimoderasi di Filament

Contoh konkret dalam sistem Anda:

> “PT Maju Jaya membuka posisi Accounting Staff”

Itu adalah satu record di tabel `job_vacancies`.

Jadi:

Lowongan = entitas data / postingan.

---

# 2️⃣ Karir

Karir bukan hanya lowongan.

Karir adalah **perjalanan profesional alumni**.

Contoh:

* Alumni bekerja di Bank BUMN
* Alumni menjadi CEO startup
* Alumni pindah karir ke Tech
* Alumni membuka usaha sendiri

Karir itu melekat pada profil alumni.

Artinya secara sistem:

Karir cocok menjadi bagian dari:

```
Direktori Alumni
→ Profil Alumni
   → Riwayat Karir
   → Posisi Saat Ini
   → Perusahaan
```

Karir ≠ Lowongan
Karir = atribut profesional alumni

---

# 3️⃣ Jejaring Profesional

Ini lebih luas lagi.

Jejaring Profesional berarti:

* Alumni saling terhubung
* Alumni membuka peluang
* Alumni mereferensikan sesama alumni
* Alumni berbagi kesempatan kerja

Dalam sistem, jejaring bisa berarti:

* Direktori Alumni publik
* Filter berdasarkan bidang
* Filter berdasarkan angkatan
* Kontak profesional
* Alumni bisa DM (fase lanjut)

Jejaring adalah ekosistem.
Lowongan hanya salah satu hasil dari jejaring.
