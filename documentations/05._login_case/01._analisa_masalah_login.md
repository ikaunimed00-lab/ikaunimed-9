Jawab singkat dan tepat:

Ini **bukan masalah React**, bukan juga Filament.
Ini masalah **session + redirect race condition saat login pertama kali**.

---

## Kenapa Terjadi?

Saat login pertama:

1. Login sukses ✅
2. Redirect ke `/admin`
3. Tapi:

   * Session belum fully established
   * Cache / config belum sinkron
   * Atau middleware panel belum resolve user

Akibatnya:

```
/admin → 500
/_boost/browser-logs → 401
```

Begitu Anda buka homepage dulu:

* Session sudah stabil
* Cookie sudah tersimpan
* Middleware resolve dengan benar
* Maka `/admin` normal

---

## Penyebab Paling Umum di Laravel + Filament + Inertia

Biasanya salah satu ini:

### 1️⃣ Redirect manual pakai `redirect('/admin')`

Harusnya pakai:

```php
return redirect()->intended('/admin');
```

---

### 2️⃣ Session driver bermasalah

Cek `.env`:

```
SESSION_DRIVER=file
```

Jangan pakai `array`.

---

### 3️⃣ Cache belum bersih

Jalankan:

```bash
php artisan optimize:clear
```

---

### 4️⃣ Middleware web tidak terpasang benar di route `/admin`

Pastikan Filament pakai middleware `web`.

---

## Kenapa 401 di `_boost/browser-logs`?

Itu dari package dev tool (boost / logger).
Dia kirim log sebelum auth siap.
Abaikan — bukan penyebab utama.

---
