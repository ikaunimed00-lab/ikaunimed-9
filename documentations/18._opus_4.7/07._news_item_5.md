## Tujuan

> *Slot iklan yang sudah disiapkan di `News/Index.tsx` bisa diaktifkan dengan cara yang terkontrol dan tidak mengganggu pengalaman membaca.*

Cakupan:

- Kebijakan tertulis: provider, batas iklan per layar, posisi yang valid, dan **master switch** global.
- Satu sumber konfigurasi (controller helper `buildAdsConfig()`) yang mengirim payload `ads` konsisten ke semua halaman.
- Hapus duplikasi placeholder iklan & ganti dengan komponen `AdsenseUnit` yang bersih.
- Pastikan saat `ads_enabled = false`, **tidak ada `<ins.adsbygoogle>` kosong** yang muncul (kebijakan Google AdSense: kotak iklan kosong tanpa konten resmi bisa menjadi alasan penolakan situs).

## Kebijakan (Single Source of Truth)

> Disimpan sebagai PHPDoc di `NewsController::buildAdsConfig()` dan di JSDoc komponen `AdLeaderboard`, `AdInline`.

1. **Master switch.** `SiteSetting::ads_enabled` adalah satu-satunya sumber yang menentukan apakah iklan tampil. `enabled === false` → komponen Ad WAJIB return `null` (tidak ada placeholder/`<ins>` kosong).
2. **Provider.** `SiteSetting::ads_provider_primary` (`adsense` | `adsterra` | `none`). Komponen Ad* hanya merender slot AdSense ketika `provider === 'adsense'`. Adsterra ditangani lewat snippet HTML di `app.blade.php` (`adsterra_script_body`).
3. **Slot id terpusat.** Semua slot id disimpan di `SiteSetting`:
   - `adsense_slot_banner` → leaderboard atas (970×90).
   - `adsense_slot_sidebar_1` → sidebar 300×250.
   - `adsense_slot_sidebar_2` → sidebar 300×600.
   - `adsense_slot_inline_article` → in-article (artikel detail).
   - `adsense_slot_list_item` → in-feed (listing berita).
4. **Batas iklan per halaman News listing (`/news`):**
   - 1 leaderboard atas.
   - 1 in-feed setiap **4 berita** (idx 4, 8, 12, 16). Sebelumnya pola tidak konsisten + duplikat dengan `AdListItem`. Sekarang seragam.
   - 2 sidebar (rectangle + half-page) di area xl ≥1280px saja.
5. **Batas iklan per halaman News detail (`/news/{slug}`):**
   - 1 in-article (di paragraf tengah konten).
   - Tidak ada sidebar ad di halaman detail (fokus reader).
6. **Slot kosong = tidak render.** Bila `enabled=true` tapi slot id belum diisi di Site Settings → komponen `return null` agar tidak ada `<ins data-ad-slot="">` kosong.

## Perubahan yang Dieksekusi

### 1. `app/Http/Controllers/NewsController.php` — `buildAdsConfig()` terpusat

**Masalah:** payload `ads` di `index()` & `show()` dibentuk inline, hanya mengirim 2 slot (`inline_article_slot`, `infeed_slot`). Sidebar dan leaderboard tidak terkirim.

**Perbaikan:** ekstrak ke private method `buildAdsConfig(): array` dengan PHPDoc kebijakan lengkap dan 7 field konsisten:

```php
private function buildAdsConfig(): array
{
    return [
        'enabled' => (bool) SiteSetting::getValue('ads_enabled', false),
        'provider' => SiteSetting::getValue('ads_provider_primary', 'adsense'),
        'leaderboard_slot' => SiteSetting::getValue('adsense_slot_banner'),
        'sidebar_1_slot' => SiteSetting::getValue('adsense_slot_sidebar_1'),
        'sidebar_2_slot' => SiteSetting::getValue('adsense_slot_sidebar_2'),
        'inline_article_slot' => SiteSetting::getValue('adsense_slot_inline_article'),
        'infeed_slot' => SiteSetting::getValue('adsense_slot_list_item'),
    ];
}
```

`index()` dan `show()` keduanya: `$adsConfig = $this->buildAdsConfig();`.

### 2. `resources/js/components/AdLeaderboard.tsx` — guard + AdsenseUnit

**Sebelum:** placeholder static dengan `<div id="ad-leaderboard-slot">` kosong.

**Sesudah:**

- Props baru: `slot?: string | null`, `enabled?: boolean`, `provider?: string`.
- Guard: `shouldRender = enabled && provider === 'adsense' && Boolean(slot)`. Bila false → `return null`.
- Bila true → render label kecil "Advertisement" + `<AdsenseUnit slot={slot} format="auto" />`.

### 3. `resources/js/components/AdInline.tsx` — guard + AdsenseUnit

**Sebelum:** kotak abu-abu selalu render (siapa pun bisa tertinggal placeholder kosong di tengah artikel).

**Sesudah:** sama dengan `AdLeaderboard` — `enabled` + `provider` + `slot` truthy → render `<AdsenseUnit>`. Selain itu `return null`.

### 4. `resources/js/Pages/News/Index.tsx` — wiring slot baru

- Interface `AdsConfig` diperluas (`enabled`, `provider`, `leaderboard_slot`, `sidebar_1_slot`, `sidebar_2_slot`, `inline_article_slot`, `infeed_slot`).
- `<AdLeaderboard enabled={ads?.enabled} provider={ads?.provider} slot={ads?.leaderboard_slot} />`.
- **In-feed** disederhanakan ke pola `(idx + 1) % 4 === 0` dengan guard `ads?.enabled && ads?.infeed_slot`. **Hapus** `<AdListItem afterItem={...}>` (duplikasi sistem) dan import-nya.
- **Sidebar kanan** (`xl:col-span-2`): dua placeholder static `<div id="ad-medium-rect-1/half-page-1">` diganti dengan `<AdsenseUnit slot={ads.sidebar_1_slot|sidebar_2_slot}>` dengan guard `ads?.enabled` di luar.
- Setiap kotak iklan ditandai label kecil "Advertisement" untuk transparansi & sesuai best practice AdSense.

### 5. `resources/js/Pages/News/Show.tsx` — guard + cleanup

- Interface `AdsConfig` disinkronkan.
- `<AdInline enabled={ads?.enabled} provider={ads?.provider} slot={ads?.inline_article_slot} />`.
- **Hapus import** `AdSidebar` yang tidak terpakai.

## Catatan untuk Langkah Berikutnya

- **Aktifkan iklan secara nyata** memerlukan langkah operasional di Filament Site Settings: isi `adsense_client_id` (sudah ada `ca-pub-3622809427438663` di [`documentations/14._adsense/01._google_adsense.md`](../14._adsense/01._google_adsense.md)) dan slot id real per posisi. Jangan dilakukan oleh agen — dokumentasinya berisi kredensial.
- **Adsterra** bisa diaktifkan paralel via `adsterra_enabled = true` + `adsterra_script_body` (snippet di `documentations/14._adsense/02._adsterra.md`) — script disuntik ke `<body>` oleh `app.blade.php`. Komponen Ad* di TSX tetap diam karena provider mismatch — tidak ada konflik.
- **Jika kelak butuh slot baru** (mis. mid-article-2, in-list-mobile-only), tambahkan key di `HomepageSeeder` (`adsense_slot_*`) + field di `buildAdsConfig()` + interface `AdsConfig` di front-end. Pola sudah konsisten.
