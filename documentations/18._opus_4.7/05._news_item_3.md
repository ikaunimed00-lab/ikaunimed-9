# News Item 3 — Standarkan Input & Validasi Video (`video_urls`)

> Tanggal eksekusi: **25 April 2026**
> Eksekutor: AI Assistant (Claude Opus 4.7)
> Sumber target: [`documentations/13._news/03._news_execution_plan.md`](../13._news/03._news_execution_plan.md) poin **3. Standarkan Input & Validasi Video (`video_urls`)**.

---

## Tujuan

> *Admin tidak bingung cara mengisi video, dan tampilan video di frontend selalu rapi.*

Cakupan:

- Pola input yang **jelas** untuk `video_urls` di form Filament (1 tag = 1 URL).
- **Validasi ringan** dua arah:
  - Maksimum jumlah video per berita (10).
  - Format URL dasar (harus URL valid, panjang wajar).
  - Domain YouTube/TikTok diutamakan; URL lain diterima sebagai **fallback link**.
- Pertahankan logika embed YouTube/TikTok di frontend.
- Pastikan fallback **"Tonton Video"** rapi & responsif untuk URL non-embed.

---

## Diagnosa Singkat (Sebelum Eksekusi)

| File | Kondisi sebelum |
|------|-----------------|
| `app/Filament/Resources/News/Schemas/NewsForm.php` | `TagsInput::make('video_urls')` memakai `->separator(',')`. **Bug latent** untuk model `News` yang punya cast `'video_urls' => 'array'`: di Filament v5 (`vendor/filament/forms/src/Components/TagsInput.php`), `separator()` mengaktifkan `dehydrateStateUsing` yang **men-implode array ke string** sebelum ke Eloquent — dan cast `array` lalu `json_encode` string itu, menghasilkan double-encoded JSON `"\"url1, url2\""` di DB (rusak untuk berita dengan ≥2 video). Selain itu **tidak ada batas jumlah video** dan **tidak ada validasi per-URL**. |
| `app/Http/Requests/StoreNewsRequest.php` & `UpdateNewsRequest.php` | Aturan hanya `'video_urls' => 'nullable\|array'` + `'video_urls.*' => 'required\|url'`. **Tanpa `max`** untuk jumlah dan panjang URL, sehingga teoretis admin bisa menempel 1.000 URL dengan panjang masing-masing 100 KB. |
| `resources/js/Pages/News/Show.tsx` | Logika embed YouTube/Shorts/TikTok sudah baik. Tapi **fallback "Tonton Video"** untuk URL non-embed hanya menampilkan ikon + teks generik — pembaca tidak tahu domain tujuan, dan link non-`http(s)` (mis. `javascript:` jika data lama bocor) bisa ter-render sebagai href aktif. |
| `app/Models/News.php` (cast `video_urls` ⇒ `array`) | Sudah benar dan tidak perlu diubah — yang salah adalah pasangan `separator()` di Filament. |

> Smoke test (tinker) di DB nyata: 14 berita total, 5 sample berita dengan `video_urls` non-kosong **semua tersimpan sebagai JSON array yang benar**. Artinya bug `separator(',')` **belum sempat menyebabkan kerusakan data** karena seluruh berita yang ada hanya 1 video — implode 1 elemen = string tunggal yang tetap valid. Risiko aktif saat admin pertama kali memasukkan 2+ URL setelah hari ini.

## Perubahan yang Dieksekusi

### 1. `app/Filament/Resources/News/Schemas/NewsForm.php`

**Masalah:** `->separator(',')` + tanpa batas + tanpa validasi per item.

**Perbaikan:**

- **Hapus `->separator(',')`** → state tetap array, cast `array` di model menulis JSON array yang konsisten.
- **`->splitKeys(['Enter'])`** → hanya tombol Enter yang men-split; URL yang punya `,` di parameter tidak akan pecah salah.
- **`->reorderable()`** → admin bisa drag-drop urutan video.
- **`->rules(['array', 'max:10'])`** → maksimum 10 video per berita di form-level.
- **`->nestedRecursiveRules(['url', 'max:2048'])`** → setiap item wajib URL dan maks. 2048 karakter.
- **`->validationMessages([...])`** → pesan error Bahasa Indonesia.
- **`->placeholder` & `->helperText`** diperjelas: jelaskan batas maks. 10 video, dukungan YouTube/Shorts/TikTok, dan bahwa URL lain akan ditampilkan sebagai tautan **"Tonton Video"** (fallback eksplisit, bukan kejutan).

```php
// SESUDAH
TagsInput::make('video_urls')
    ->label('Daftar Video (YouTube/TikTok)')
    ->placeholder('Tempel satu URL video lalu tekan Enter')
    ->helperText('Satu tag = satu URL video. Maks. 10 video per berita. Mendukung YouTube (termasuk /shorts), TikTok; URL lain akan ditampilkan sebagai tautan "Tonton Video".')
    ->splitKeys(['Enter'])
    ->reorderable()
    ->rules(['array', 'max:10'])
    ->nestedRecursiveRules(['url', 'max:2048'])
    ->validationMessages([
        'max' => 'Maksimal 10 URL video per berita.',
    ]),
```

### 2. `app/Http/Requests/StoreNewsRequest.php` & `UpdateNewsRequest.php`

**Masalah:** validasi video_urls longgar di backend (ada admin yang submit via API atau bypass form? min validasi tetap perlu).

**Perbaikan:** sinkronkan dengan form Filament + tambah pesan Bahasa Indonesia.

```php
// SESUDAH (kedua FormRequest)
'video_urls'   => 'nullable|array|max:10',
'video_urls.*' => 'required|url|max:2048',

// messages():
'video_urls.max'       => 'Maksimal 10 URL video per berita',
'video_urls.*.url'     => 'Format URL video tidak valid',
'video_urls.*.max'     => 'URL video terlalu panjang (maksimal 2048 karakter)',
```

### 3. `resources/js/Pages/News/Show.tsx`

**Masalah:** fallback "Tonton Video" tidak menampilkan tujuan link; tidak ada guard untuk URL non-`http(s)`.

**Perbaikan pada blok "Galeri Video":**

- Tambah helper `getSafeHostname(url)` (`new URL(url).hostname` dengan strip `www.`).
- Tambah guard `isAbsoluteHttp = /^https?:\/\//i.test(url)`:
  - Jika URL absolut HTTP/HTTPS dan bukan YouTube/TikTok yang dapat di-embed → render kartu fallback dengan ikon 🔗, teks "Tonton Video", dan **hostname kecil di bawahnya** sehingga pembaca tahu mau diarahkan ke domain mana sebelum klik.
  - Jika URL **bukan** absolut HTTP/HTTPS (mis. data rusak / `javascript:` / relatif) → render kartu peringatan dengan ikon ⚠️ dan teks "URL video tidak valid" — **tidak ada `<a>` aktif**, mencegah kebocoran XSS.
- `rel="noopener noreferrer nofollow"` (tambah `nofollow` untuk SEO bersih saat fallback ke domain pihak ketiga).
- Tetap `aspect-video`, `rounded-xl`, dan `break-all` pada hostname agar mobile-friendly.

```tsx
const getSafeHostname = (input: string): string | null => {
    try { return new URL(input).hostname.replace(/^www\./, ''); } catch { return null; }
};
// ...
if (!embedUrl) {
    const hostname = getSafeHostname(url);
    const isAbsoluteHttp = /^https?:\/\//i.test(url);
    return (
        <div className="aspect-video bg-gray-50 rounded-xl ... px-4">
            {isAbsoluteHttp ? (
                <a href={url} target="_blank" rel="noopener noreferrer nofollow" ...>
                    <span>🔗</span>
                    <span>Tonton Video</span>
                    {hostname && <span className="text-xs ... break-all">{hostname}</span>}
                </a>
            ) : (
                <div ...>
                    <span>⚠️</span>
                    <span>URL video tidak valid</span>
                </div>
            )}
        </div>
    );
}
```
