# 🧭 1️⃣ Struktur Halaman (Macro Layout)

Urutan vertikal halaman:

```
[ Hero Section ]
[ Filter Bar ]
[ Sorting + Result Info ]
[ Grid Kartu Alumni ]
[ Pagination ]
[ CTA Section (untuk publik) ]
```

Kita uraikan satu per satu.

---

# 🟢 2️⃣ HERO SECTION

### 🎯 Tujuan:

Menjelaskan positioning halaman secara strategis.

### Struktur:

**Heading (H1):**

> Direktori Alumni IKA UNIMED

**Subheading:**

> Temukan dan terhubung dengan alumni dari berbagai bidang profesional.

**Teks Penjelas Singkat (1–2 kalimat):**

> Direktori ini menampilkan profil profesional alumni yang telah melengkapi data karirnya. Untuk bergabung dan menampilkan profil Anda, silakan daftar atau masuk ke akun Anda.

**CTA Button (Publik):**

* Primary: `Gabung & Tampilkan Profil Anda`
* Secondary (jika sudah login): `Lengkapi Profil Saya`

---

# 🟡 3️⃣ FILTER BAR (Sticky / Fixed on Scroll)

Diletakkan tepat di bawah Hero.

### Filter Utama (Versi 1):

1. 🔎 Search Nama (input text)
2. 🏷 Bidang Pekerjaan (dropdown)
3. 🎓 Angkatan (tahun masuk – dropdown / range)
4. 💼 Status Pekerjaan (dropdown)

Optional v1.1:
5. 📚 Prodi

---

### Urutan Visual (Left → Right):

```
[Search] [Bidang] [Angkatan] [Status]   (Clear Filter)
```

Filter harus ringan, tidak terlalu banyak.

---

# 🔵 4️⃣ SORTING & INFO BAR

Di atas grid kartu:

Kiri:

> Menampilkan 120 alumni

Kanan:
Dropdown sorting:

* Terbaru diperbarui (default)
* Angkatan terbaru
* Angkatan terlama

👉 Terbaru diperbarui

Bagian atas:

# 🎯 8️⃣ Aturan Perilaku (Behavior Rules)

1. Hanya tampil jika:

   * public_profile = true
   * Level ≥ 1

2. Jika filter kosong → tampil semua

3. Jika tidak ada hasil:
   Tampilkan:

   > Tidak ditemukan alumni sesuai filter Anda.
