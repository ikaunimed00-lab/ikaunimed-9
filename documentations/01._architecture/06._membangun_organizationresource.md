# Blueprint Implementasi OrganizationResource

Dokumen ini merinci rencana migrasi dan implementasi `OrganizationResource` di Filament untuk mengelola struktur organisasi IKA UNIMED (PP, DPW, DPC).

## 1. Konsep & Tujuan
- **Centralized Management**: Mengelola seluruh tingkatan organisasi dalam satu interface.
- **Hierarchical Structure**: Mendukung struktur parent-child (misal: DPW membawahi beberapa DPC).
- **Access Control**: Hanya Admin Pusat yang dapat mengelola daftar organisasi. Admin Wilayah/Cabang hanya bisa melihat (read-only) atau mengelola anggota di bawahnya (akan diimplementasikan di resource berbeda jika perlu).

## 2. Struktur Data (Model: Organization)
- `name`: Nama Organisasi.
- `slug`: Auto-generated slug.
- `type`: Enum (pp, dpw, dpc).
- `parent_id`: Relasi ke organisasi tingkat di atasnya.
- `logo`: File upload logo.
- `description`, `address`, `phone`, `email`: Informasi kontak & profil.
- `is_active`: Status aktif organisasi.

## 3. Implementasi Filament

### A. Form Schema (OrganizationForm)
Dibagi menjadi 2 Section:
1. **Identitas & Hirarki**:
    - `name` (TextInput, required, auto-slug)
    - `slug` (TextInput, disabled/readonly)
    - `type` (Select: PP, DPW, DPC)
    - `parent_id` (Select: Relasi ke sesama Organization, difilter berdasarkan type)
    - `is_active` (Toggle)
2. **Profil & Kontak**:
    - `logo` (FileUpload)
    - `email` (TextInput, email)
    - `phone` (TextInput)
    - `address` (Textarea)
    - `description` (RichEditor/Textarea)

### B. Table Configuration (OrganizationTable)
- **Columns**: Logo, Name, Type (Badge), Parent, Status (Toggle).
- **Filters**: Type, Status.
- **Actions**: Edit, Delete.

### C. Keamanan (Resource Level)
- `canViewAny()`: Hanya admin (isWriter) yang bisa melihat.
- `canCreate()`, `canEdit()`, `canDelete()`: Hanya Admin Pusat (`isCentralAdmin`) yang memiliki akses penuh.

## 4. Tahapan Kerja
1. Generate Resource: `php artisan make:filament-resource Organization --generate`.
2. Refactor struktur file ke sub-folder `Organization/`.
3. Implementasi `OrganizationForm` dan `OrganizationTable`.
4. Update `OrganizationResource` untuk proteksi akses (Authorization).
5. Dokumentasi di `03._migration_log.md`.
