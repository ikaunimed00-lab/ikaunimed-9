  ```php
  namespace App\Policies;

  use App\Models\Course;
  use App\Models\User;

  class CoursePolicy
  {
      public function manage(User $user, Course $course): bool
      {
          if ($user->isAdmin() || $user->isEditor()) {
              return true;
          }

          return $user->isWriter() && $course->created_by === $user->id;
      }

      public function enroll(User $user, Course $course): bool
      {
          if (! $user->isSubscriber()) {
              return false;
          }

          if ($course->status !== 'published') {
              return false;
          }

          return ! $course->is_paid;
      }
  }
  ```

  - `manage`: admin/editor selalu boleh; writer hanya jika dia pemilik course (`created_by`).
  - `enroll`: hanya `subscriber`, course harus `published`, dan hanya untuk kelas gratis (`is_paid == false`) sesuai MVP (paid flow nanti pakai Midtrans).

  public function show(Course $course): Response
  {
      $user = Auth::user();

      if ($course->status !== 'published') {
          if (! $user) {
              abort(404);
          }

          $isOwner = $course->created_by && $user->id === $course->created_by;

          if (! $user->isAdmin() && ! $user->isEditor() && ! ($user->isWriter() && $isOwner)) {
              abort(404);
          }
      }

      $course->load([
          'category',
          'creator:id,name',
          'modules.lessons',
          'lessons',
      ]);

      $related = Course::query()
          ->where('status', 'published')
          ->where('id', '!=', $course->id)
          ->when($course->category_id, function ($q) use ($course) {
              $q->where('category_id', $course->category_id);
          })
          ->limit(3)
          ->get();

      $enrollment = null;
      $lessonProgress = [];

      if ($user && $user->isSubscriber()) {
          $enrollment = Enrollment::where('user_id', $user->id)
              ->where('course_id', $course->id)
              ->first();

          if ($enrollment) {

              if ($lessonIds->isNotEmpty()) {

                      ->pluck('is_completed', 'lesson_id');

          }

      return Inertia::render('Course/Show', [

          'related' => $related,
          'enrollment' => $enrollment,

      ]);

  ```php
  public function enroll(Request $request, Course $course): RedirectResponse
  {
      $this->authorize('enroll', $course);

      $user = $request->user();

      $enrollment = Enrollment::firstOrCreate(
          [
              'user_id' => $user->id,
              'course_id' => $course->id,
          ],
          [
              'status' => 'active',
              'started_at' => now(),
          ]
      );

      if (! $enrollment->started_at) {
          $enrollment->started_at = now();
          $enrollment->status = 'active';
          $enrollment->save();
      }

      return redirect()
          ->route('courses.show', $course->slug)
          ->with('success', 'Anda berhasil mendaftar course ini.');
  }
  ```

- **Update progress pelajaran (`completeLesson`)**

  ```php
  public function completeLesson(Request $request, Course $course, Lesson $lesson): RedirectResponse
  {
      $user = $request->user();

      if ($lesson->course_id !== $course->id) {
          abort(404);
      }

      $enrollment = Enrollment::where('user_id', $user->id)
          ->where('course_id', $course->id)
          ->first();

      if (! $enrollment) {
          abort(403);
      }

      $progress = LessonProgress::firstOrCreate(
          [
              'user_id' => $user->id,
              'lesson_id' => $lesson->id,
          ]
      );

      if (! $progress->is_completed) {
          $progress->is_completed = true;
          $progress->completed_at = now();
          $progress->save();

          $lessonIds = $course->lessons()->pluck('id');

          if ($lessonIds->isNotEmpty()) {
              $completedCount = LessonProgress::where('user_id', $user->id)
                  ->whereIn('lesson_id', $lessonIds)
                  ->where('is_completed', true)
                  ->count();

              $totalLessons = $lessonIds->count();

              if ($totalLessons > 0) {
                  $percentage = (int) floor(($completedCount / $totalLessons) * 100);

                  $enrollment->progress_percentage = $percentage;

                  if ($percentage === 100 && ! $enrollment->completed_at) {
                      $enrollment->completed_at = now();
                      $enrollment->status = 'completed';
                  }

                  $enrollment->save();
              }
          }
      }

      return redirect()
          ->back()
          ->with('success', 'Progress belajar berhasil diperbarui.');
  }
  ```

  - Safety:
    - Cek `lesson.course_id` sesuai `course` di URL.
    - Wajib sudah enroll, kalau belum → 403.
  - Progress:
    - Menandai `LessonProgress.is_completed = true`.
    - Hitung ulang `progress_percentage` di `Enrollment`.
    - Jika 100%, set `status = 'completed'` dan `completed_at`.

## 03. Ringkasan Implementasi E‑Learning MVP – Flow Nyata

Tahap ini menghidupkan alur nyata e‑learning di frontend dan backend untuk:

- Katalog kelas (listing publik)
- Halaman detail / viewer course
- Enroll course oleh subscriber
- Pencatatan progres belajar per lesson
- Role mapping yang selaras dengan arsitektur (admin/editor/writer/subscriber)

Semua perubahan mengikuti struktur modul e‑learning yang sudah disiapkan di tahap sebelumnya (model Course, Lesson, Enrollment, LessonProgress, dsb.).

---

## 1. Policy dan Role Mapping

**Tujuan**: Menentukan siapa yang boleh mengelola course dan siapa yang boleh melakukan enroll, dengan tetap mengikuti pola role global (admin, editor, writer, subscriber).

### 1.1. CoursePolicy

**File**: `app/Policies/CoursePolicy.php`

Metode utama:

- `manage(User $user, Course $course): bool`
  - `admin` dan `editor` selalu boleh mengelola course.
  - `writer` boleh mengelola course **jika** dia pemilik course (`created_by` sama dengan `user->id`).
- `enroll(User $user, Course $course): bool`
  - Hanya `subscriber` yang boleh enroll.
  - Course harus berstatus `published`.
  - Hanya course **gratis** (`is_paid = false`) yang bisa di‑enroll di tahap MVP ini.

Ini selaras dengan strategi bahwa konten akademik dikelola oleh admin/editor/writer, sementara konsumsi konten dilakukan oleh subscriber.

### 1.2. Registrasi Policy

**File**: `app/Providers/AuthServiceProvider.php`

Penambahan mapping:

- `Course::class => CoursePolicy::class`

Dengan ini, pemanggilan `Gate::authorize('enroll', $course)` atau `$this->authorize('enroll', $course)` otomatis menggunakan `CoursePolicy`.

### 1.3. Relasi Kategori Course

**File**: `app/Models/Course.php`

Penambahan relasi:

- `category(): belongsTo(CourseCategory::class, 'category_id')`

Relasi ini dipakai untuk menampilkan dan mem‑filter course berdasarkan kategori di katalog dan menampilkan kategori di halaman detail.

---

## 2. Routing E‑Learning – Katalog, Detail, Enroll, Progress

Semua route publik dan e‑learning MVP didefinisikan di:

**File**: `routes/web.php`

### 2.1. Katalog & Detail Course (Publik)

- `GET /courses` → `CourseController@index` → `courses.index`
  - Menampilkan katalog course yang berstatus `published`.
- `GET /courses/{course:slug}` → `CourseController@show` → `courses.show`
  - Menampilkan detail course + struktur modul/lesson.
  - Course non‑`published` hanya dapat diakses admin/editor atau writer pemilik.

Route ini tidak memiliki middleware khusus; akses publik diizinkan untuk course yang sudah dipublikasikan. Untuk course draft/unpublished, access control dilakukan di controller.

### 2.2. Enroll Course (Subscriber)

- `POST /courses/{course:slug}/enroll` → `CourseController@enroll` → `courses.enroll`

Middleware:

- `auth` → user harus login.
- `role:subscriber` → hanya subscriber yang boleh mencoba enroll.
- `throttle:10,1` → membatasi spam enroll.

Di dalam controller, masih ada lapis **policy** (`CoursePolicy@enroll`) yang memastikan:

- Hanya course `published` dan `gratis` yang bisa di‑enroll.

### 2.3. Update Progress Lesson

- `POST /courses/{course:slug}/lessons/{lesson}/complete` → `CourseController@completeLesson` → `courses.lessons.complete`

Middleware:

- `auth`
- `role:subscriber`

Logika utama:

- Validasi bahwa `lesson` memang milik `course` di URL.
- Pastikan user sudah memiliki `Enrollment` aktif untuk course tersebut.
- Tandai `LessonProgress` untuk kombinasi `(user, lesson)` sebagai `is_completed = true`.
- Hitung ulang persentase progress (`progress_percentage`) di `Enrollment` berdasarkan jumlah lesson yang selesai.
- Jika semua lesson selesai (100%), set `Enrollment.status = 'completed'` dan isi `completed_at`.

## 3. CourseController – Katalog, Detail/Viewer, Enroll, Progress

**File**: `app/Http/Controllers/CourseController.php`

### 3.1. `index` – Katalog Course

Input:

- Query params: `search`, `category` (slug), `level`, `price_type` (`free`/`paid`).

Perilaku:

- Query `Course` berstatus `published`, dengan eager load `category`.
- Filter dinamis:
  - `search` → `title like %search%`.
  - `category` → berdasarkan slug `CourseCategory`.
  - `level` → `course.level`.
  - `price_type`:
    - `free` → `is_paid = false`.
    - `paid` → `is_paid = true`.
- Sortir berdasarkan `published_at` terbaru.
- Ambil daftar kategori (`CourseCategory`) untuk filter di frontend.
- Render Inertia ke `Course/Index` dengan:
  - `courses` (paginasi 9 per halaman),
  - `categories`,
  - `filters` (untuk mengisi ulang form filter).

### 3.2. `show` – Detail / Viewer Course

Perilaku access control:

- Jika `course.status !== 'published'`:
  - Non‑login → 404.
  - Login:
    - Akses hanya jika:
      - admin, atau
      - editor, atau
      - writer pemilik (`created_by`).
    - Kalau tidak memenuhi → 404 (tidak bocorkan keberadaan course draft).

Data yang dimuat:

- `category`
- `creator:id,name`
- `modules.lessons` (untuk struktur silabus)
- `lessons` (untuk menghitung progress dan total lesson)

Related course:

- Ambil maksimal 3 course lain yang `published` dan (jika ada) satu kategori dengan course tersebut.

Data khusus subscriber:

- Jika user login **dan** `isSubscriber()`:
  - Cari `Enrollment` untuk `(user, course)`.
  - Jika ada enrollment:
    - Ambil semua `lesson_id` milik course.
    - Ambil map `LessonProgress` untuk user tersebut → `lesson_id => is_completed`.

Output ke Inertia `Course/Show`:

- `course`
- `related`
- `enrollment`
- `lessonProgress` (map lesson → boolean).

### 3.3. `enroll` – Enroll Course Gratis

Perilaku:

- Gunakan `$this->authorize('enroll', $course)` → `CoursePolicy@enroll`.
- `Enrollment::firstOrCreate` dengan key `(user_id, course_id)`:
  - Pertama kali:
    - `status = 'active'`
    - `started_at = now()`
  - Jika sudah ada tapi belum ada `started_at`:
    - Isi `started_at` dan set `status = 'active'`.
- Redirect kembali ke `courses.show` dengan flash message sukses.

Ini membuat operasi enroll **idempotent** dan aman terhadap klik berulang.

### 3.4. `completeLesson` – Update Progress Belajar

Guarding:

- Pastikan `lesson.course_id == course.id` → jika tidak, 404.
- Pastikan user memiliki `Enrollment` untuk course → kalau tidak, 403.

Perilaku:

- `LessonProgress::firstOrCreate` untuk `(user_id, lesson_id)`.
- Jika sebelumnya belum selesai:
  - Set `is_completed = true`, `completed_at = now()`.
  - Hitung ulang:
    - `lessonIds` = semua `lesson.id` milik course.
    - `completedCount` = jumlah lesson yang `is_completed = true` untuk user.
    - `percentage = floor(completedCount / totalLessons * 100)`.
  - Update `Enrollment.progress_percentage`.
  - Jika 100% dan `completed_at` masih null:
    - Set `Enrollment.completed_at = now()`.
    - Set `Enrollment.status = 'completed'`.
- Redirect `back()` dengan flash message sukses.

## 6. Ringkasan Alur Pengguna per Peran

### 6.1. Pengunjung Publik (Belum Login)

- Bisa:
  - Mengakses `/courses` (katalog course published).
  - Mengakses `/courses/{slug}` untuk course yang `published`.
- Tidak bisa:
  - Enroll course.
  - Menandai progress lesson.

### 6.2. Subscriber (Alumni) Login

- Bisa:
  - Mengakses katalog dan detail course published.
  - Enroll course **gratis**.
  - Menandai lesson sebagai selesai dan melihat progress bar di halaman detail.
  - Melanjutkan belajar (progress tersimpan di `Enrollment` dan `LessonProgress`).
- Tidak bisa:
  - Enroll course berbayar (tahap ini belum mengaktifkan pembayaran).

### 6.3. Admin / Editor / Writer

- Admin / Editor:
  - Bisa melihat course non‑published melalui halaman detail.
- Writer:
  - Bisa melihat course non‑published **yang dia buat sendiri**.

Dengan demikian, flow MVP sudah menyatu dengan role architecture global:

- Domain **konsumsi pembelajaran** → `subscriber`.
- Domain **produksi konten** → `admin/editor/writer`.
