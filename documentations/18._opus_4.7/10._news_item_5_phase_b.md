# News Item 5 — Phase B AdSense (Persiapan Kode `data-ad-client`)

> Tanggal eksekusi: **26 April 2026**
> Eksekutor: AI Assistant (Claude Opus 4.7)
> Sumber target: tindak lanjut [`09._news_item_5_aktivasi.md`](./09._news_item_5_aktivasi.md) bagian **"Catatan Tambahan — Komponen `AdsenseUnit.tsx`"** dan **"Phase B — Saat AdSense Approved Nanti"**.

---

## Tujuan

> *Menambah jalur Publisher ID (`data-ad-client`) ke setiap `<ins.adsbygoogle>` yang dirender komponen React, agar saat AdSense approved nanti aktivasi cukup di Site Settings tanpa sentuh kode lagi.*

Cakupan:

- **Persiapan kode** — bukan aktivasi nyata. AdSense path tetap mati (`ads_enabled=false`) sampai user mendapatkan slot ID asli dari AdSense console.
- Tambah `client_id` ke payload `ads` yang dikirim controller ke React.
- Tambah prop `client?: string | null` ke komponen Ad* (`AdsenseUnit`, `AdLeaderboard`, `AdInline`).
- Saat `client` truthy → `<ins>` mendapat atribut `data-ad-client="ca-pub-..."` eksplisit (best practice Google AdSense).
- Saat `client` falsy/kosong → `<ins>` **tidak** menampilkan atribut tersebut → fallback ke mode auto-infer dari URL script (`adsbygoogle.js?client=...`) di `app.blade.php`. Komponen tetap aman dipakai sebelum Phase B aktif.

---

## Diagnosa Singkat (Sebelum Eksekusi)

| Aspek | Kondisi sebelum |
|-------|-----------------|
| `app.blade.php` | `<script ...adsbygoogle.js?client={{ $adsenseClientId }}>` di-inject saat `ads_enabled=true && provider=adsense`. ✓ |
| Blade partial `components/ads/{banner,sidebar,inline,list}.blade.php` | Sudah set `<ins data-ad-client="{{ $clientId }}">` dengan benar. ✓ |
| `resources/js/components/AdsenseUnit.tsx` | **Hanya set `data-ad-slot`**, tidak `data-ad-client`. Bekerja via fallback auto-infer, tapi best practice Google **menganjurkan** atribut eksplisit per `<ins>`. |
| `resources/js/components/AdLeaderboard.tsx` & `AdInline.tsx` | Tidak meneruskan Publisher ID — tidak ada channel untuk passing ke `AdsenseUnit`. |
| `NewsController::buildAdsConfig()` | Mengirim 6 field: `enabled`, `provider`, 4 slot id, 1 inline_article_slot. **Tidak mengirim `client_id`** sama sekali ke React. |
| `AdsConfig` interface (`News/Index.tsx`, `News/Show.tsx`) | Tidak ada field `client_id`. |

> Risiko sebelum perubahan: saat user kelak flip `ads_enabled=true` dan isi `adsense_client_id='ca-pub-3622809427438663'`, atribut `data-ad-client` di `<ins>` React **tidak otomatis ada** — Google bisa flag mismatch policy karena URL script-nya jelas pakai `ca-pub-X` tapi `<ins>` tanpa atribut. Akibatnya iklan AdSense React-side bisa stuck blank meski Adsterra (Adsense-paralel) jalan normal.

## Perubahan yang Dieksekusi

### 1. `app/Http/Controllers/NewsController.php`

Tambah field `client_id` ke `buildAdsConfig()` — single source of truth payload `ads`.

```php
private function buildAdsConfig(): array
{
    return [
        'enabled' => (bool) SiteSetting::getValue('ads_enabled', false),
        'provider' => SiteSetting::getValue('ads_provider_primary', 'adsense'),
        'client_id' => SiteSetting::getValue('adsense_client_id'),   // BARU
        'leaderboard_slot' => SiteSetting::getValue('adsense_slot_banner'),
        'sidebar_1_slot' => SiteSetting::getValue('adsense_slot_sidebar_1'),
        'sidebar_2_slot' => SiteSetting::getValue('adsense_slot_sidebar_2'),
        'inline_article_slot' => SiteSetting::getValue('adsense_slot_inline_article'),
        'infeed_slot' => SiteSetting::getValue('adsense_slot_list_item'),
    ];
}
```

PHPDoc kontrak diperbarui:

> `client_id` — Publisher ID AdSense (`ca-pub-XXXXXXXXXXXXXXXX`) untuk atribut `data-ad-client` di setiap `<ins.adsbygoogle>`. Saat string kosong, komponen tetap render `<ins>` tanpa atribut tersebut — fallback ke mode auto-infer dari `<script ?client=...>`.

### 2. `resources/js/components/AdsenseUnit.tsx`

Tambah prop `client?: string | null` dan set `data-ad-client` saat truthy:

```tsx
interface AdsenseUnitProps {
  slot: string;
  client?: string | null;   // BARU
  // ...
}

const props: Record<string, string> = {
  'data-ad-slot': slot,
};
if (client) {
  props['data-ad-client'] = client;
}
// ...
return <ins className="adsbygoogle" style={style} {...props} />;
```

Behavior:

| `client` | `<ins>` keluaran |
|----------|------------------|
| `'ca-pub-3622809427438663'` | `<ins class="adsbygoogle" data-ad-slot="..." data-ad-client="ca-pub-3622809427438663" ...>` ★ Phase B |
| `null` / `undefined` / `''` | `<ins class="adsbygoogle" data-ad-slot="..." ...>` (tanpa atribut, fallback auto-infer) — Phase A |

Komponen TIDAK menambah gating baru: hanya konversi minor "kalau ada → set, kalau tidak → diam".

### 3. `resources/js/components/AdLeaderboard.tsx`

Tambah `client?: string | null` di props + teruskan ke `<AdsenseUnit client={client} ...>`.

```tsx
interface AdLeaderboardProps {
  // ...
  client?: string | null;   // BARU
}

<AdsenseUnit
  slot={slot as string}
  client={client}
  format="auto"
  style={{ display: 'block', width: '100%' }}
/>
```

Tidak mengubah logika gating (`enabled && provider==='adsense' && Boolean(slot)`). Komponen tetap return `null` saat ads off.

### 4. `resources/js/components/AdInline.tsx`

Sama — tambah `client?: string | null` + teruskan ke `<AdsenseUnit>`.

### 5. `resources/js/Pages/News/Index.tsx`

- `AdsConfig` interface tambah `client_id?: string | null` dengan JSDoc penjelasan.
- 4 pemakaian Ad* di-wire:
  - `<AdLeaderboard client={ads?.client_id} ...>`
  - `<AdsenseUnit client={ads.client_id}>` — in-feed ad (idx % 4 === 0)
  - `<AdsenseUnit client={ads.client_id}>` — sidebar 1 (300×250)
  - `<AdsenseUnit client={ads.client_id}>` — sidebar 2 (300×600)

### 6. `resources/js/Pages/News/Show.tsx`

- `AdsConfig` interface tambah `client_id?: string | null` (paralel dengan `News/Index.tsx`).
- 1 pemakaian: `<AdInline client={ads?.client_id} ...>` di paragraf tengah artikel.

### Verifikasi runtime simulatif (matriks behaviour)

| `ads_enabled` | `client_id` | slot id | Hasil di `<ins>` | Hasil global script |
|---------------|-------------|---------|------------------|---------------------|
| `false` | `''` | `''` | tidak render (komponen return null) | tidak load |
| `true` | `''` | `'ca-pub-...'` (slot real) | `<ins data-ad-slot="..."` (tanpa `data-ad-client`) — fallback auto-infer | load `?client=` (kosong) ⚠ — perlu isi `client_id` paralel |
| `true` | `'ca-pub-3622809427438663'` | slot real | `<ins data-ad-slot="..." data-ad-client="ca-pub-3622809427438663">` ★ | load `?client=ca-pub-3622809427438663` |

> **Implication:** untuk memetik manfaat `data-ad-client` eksplisit, `client_id` di Site Settings harus diisi **bersamaan** dengan slot id real. Itu sudah jadi paket di "Phase B step list" di `09._news_item_5_aktivasi.md` § "Phase B — Saat AdSense Approved Nanti".

## Cara Aktivasi Phase B (Untuk User di Masa Depan)

**Prasyarat (dari Google AdSense console):**
- Situs sudah approved oleh Google AdSense.
- Publisher ID di tangan: `ca-pub-3622809427438663` (sudah ada di [`14._adsense/01._google_adsense.md`](../14._adsense/01._google_adsense.md)).
- 5 Ad Unit Slot ID (10-digit) sudah dibuat di AdSense console untuk: Banner 970×90, Sidebar 300×250, Sidebar 300×600, In-Article, In-Feed.

**Langkah aktivasi (lewat Filament Site Settings, group `Ads`):**

| Field | Set ke |
|-------|--------|
| Enable Ads (`ads_enabled`) | `true` |
| Primary Ads Provider (`ads_provider_primary`) | `adsense` (sudah default) |
| AdSense Client ID (`adsense_client_id`) | `ca-pub-3622809427438663` |
| AdSense Banner Slot (`adsense_slot_banner`) | `<10-digit-real-id>` |
| AdSense Sidebar Slot 1 (`adsense_slot_sidebar_1`) | `<10-digit-real-id>` |
| AdSense Sidebar Slot 2 (`adsense_slot_sidebar_2`) | `<10-digit-real-id>` |
| AdSense Inline Article Slot (`adsense_slot_inline_article`) | `<10-digit-real-id>` |
| AdSense List Item Slot (`adsense_slot_list_item`) | `<10-digit-real-id>` |

**Yang otomatis terjadi tanpa redeploy:**

1. `<head>` mendapat `<script ...adsbygoogle.js?client=ca-pub-3622809427438663>` (via `app.blade.php`).
2. Setiap `<ins.adsbygoogle>` di `News/Index.tsx` & `News/Show.tsx` dirender dengan `data-ad-client="ca-pub-3622809427438663"` + `data-ad-slot="<real-id>"` lengkap.
3. Adsterra (Phase A) **tetap aktif paralel** — kedua provider hidup berdampingan.

**Yang tetap perlu intervensi tim editorial:**

- Cek manual halaman `/news` & `/news/{slug}` di production untuk pastikan tidak ada layout shift dari iklan baru.
- Pantau dashboard AdSense 24–48 jam untuk pastikan impressions & clicks tercatat dengan benar.
- Bila Google flag policy violation → matikan via `ads_enabled=false` di Filament (tanpa redeploy) sampai isu selesai.

## Hal yang TIDAK Disentuh (Sengaja)

- **Blade partial** (`resources/views/components/ads/*.blade.php`): sudah set `data-ad-client` dengan benar via `SiteSetting::getValue('adsense_client_id', '...')`. Tidak perlu disentuh.
- **`app.blade.php`**: sudah inject `<script ?client=...>` dengan benar. Tidak perlu disentuh.
- **HomeController, halaman lain**: tidak menggunakan komponen Ad* React (sudah dicek via grep). Bila kelak halaman lain memakai Ad* (mis. `Shop/Index`, `Course/Show`), cukup ikuti pola yang sama: kirim `ads` config dari controller (atau pakai shared Inertia prop) lalu wiring `client={ads?.client_id}`.
- **Aktivasi nyata Phase B**: sengaja **tidak** dilakukan oleh agen — perlu Slot ID real dari AdSense console yang hanya bisa di-generate user setelah situs approved.

## Catatan untuk Langkah Berikutnya

1. **Konsumsi `ads` di luar News** — kalau modul Shop/Course/Home butuh iklan, hindari hardcode slot id. Buat helper terpusat (mis. `AdsService::buildConfig()`) yang di-share via `HandleInertiaRequests::share()` agar setiap halaman otomatis dapat payload `ads` yang sama. Saat ini hanya News yang punya. Belum mendesak.
2. **Komponen `AdsenseUnit` versi blade**: jika kelak ada page non-Inertia yang butuh AdSense React, komponen sudah siap dipakai dengan prop `client` & `slot`.
3. **Audit konsistensi atribut `<ins>`**: 6 atribut yang umum di docs Google AdSense — saat ini terimplementasi:
   - ✓ `data-ad-slot`
   - ✓ `data-ad-client` (Phase B)
   - ✓ `data-ad-format`
   - ✓ `data-ad-layout`
   - ✓ `data-full-width-responsive`
   - ⏳ `data-ad-layout-key` (untuk fluid in-feed) — tidak dipakai sekarang, tambahkan saat butuh.
