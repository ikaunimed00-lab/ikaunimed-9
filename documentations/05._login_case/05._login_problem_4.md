# 💥 Penyebab Pasti

Route Filament masih tertangkap middleware atau view Inertia.

Biasanya terjadi karena salah satu ini:

### 1️⃣ Kamu pernah override root view

Cek apakah kamu punya ini di AppServiceProvider atau tempat lain:

```php
Filament::serving(function () {
    //
});
```

atau

```php
View::share(...)
```

---

### 2️⃣ Kamu pernah ubah layout Blade global

Cek apakah file ini ada:

```
resources/views/filament/layouts/app.blade.php
```

atau

```
resources/views/layouts/app.blade.php
```

Dan mungkin kamu memasukkan:

```
@vite('resources/js/app.tsx')
```

di sana.

Kalau iya → itu sumber masalah.

# ✅ SOLUSI BERSIH

Kita pastikan Inertia middleware TIDAK global.

Buka:

```
bootstrap/app.php
```

Pastikan `HandleInertiaRequests` TIDAK ada di:

```
$middleware->web([...])
```

HARUS seperti ini (tanpa Inertia):

```php
$middleware->web([
    EncryptCookies::class,
    AddQueuedCookiesToResponse::class,
    StartSession::class,
    ShareErrorsFromSession::class,
    VerifyCsrfToken::class,
    SubstituteBindings::class,
]);
```

---

Lalu di routes/web.php:

Frontend saja yang pakai:

```php
Route::middleware(['web', HandleInertiaRequests::class])
```

Admin tidak boleh.

Kamu pernah ubah:

```
resources/views/app.blade.php
```

Dan menjadikannya layout global.

Filament tidak menggunakan file itu.
Tapi kalau kamu override default layout system, bisa tertarik.
