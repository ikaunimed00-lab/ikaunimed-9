## Perubahan yang Dieksekusi

### 1. `resources/js/Pages/News/Index.tsx` — `<Head>` SEO + OG

**Sebelum:**

```tsx
<title>Portal Berita - IKA UNIMED</title>
<meta name="description" content="Portal berita profesional dengan informasi terbaru dari Ikatan Alumni UNIMED" />
<meta property="og:title" content="Portal Berita IKA UNIMED" />
<meta property="og:description" content="Berita, artikel, dan informasi terkini" />
<meta property="og:type" content="website" />
```

**Sesudah:**

```tsx
<title>Portal Berita Alumni - IKA UNIMED</title>
<meta name="description" content="Portal berita resmi Ikatan Alumni Universitas Negeri Medan (IKA UNIMED). Informasi terkini program alumni, kisah sukses, opini, dan kabar UNIMED." />
<meta name="keywords" content="IKA UNIMED, alumni UNIMED, Universitas Negeri Medan, berita alumni, opini alumni, program alumni, kabar kampus" />
<meta property="og:title" content="Portal Berita Alumni - IKA UNIMED" />
<meta property="og:description" content="Berita, opini, dan informasi terkini dari Ikatan Alumni Universitas Negeri Medan." />
<meta property="og:image" content="/images/cta_ikaunimed-002.png" />
<meta property="og:type" content="website" />
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="Portal Berita Alumni - IKA UNIMED" />
<meta name="twitter:image" content="/images/cta_ikaunimed-002.png" />
```

Perubahan kunci:

- Judul memuat kata "Alumni" → klik di SERP lebih kontekstual.
- Description menyebut nama lengkap "Universitas Negeri Medan", "kisah sukses", "opini" — keyword bertarget.
- `keywords` (meskipun bobot SEO-nya kecil) konsisten dengan branding.
- OG image menunjuk file yang **terbukti ada di disk** (`public/images/cta_ikaunimed-002.png`).
- Twitter Card lengkap (sebelumnya tidak ada).

### 2. `resources/js/Pages/News/Show.tsx` — fallback description + OG image + schema.org

**Helper baru:**

```tsx
const FALLBACK_OG_IMAGE = '/images/cta_ikaunimed-002.png';
const ogImageUrl = imageUrl ?? FALLBACK_OG_IMAGE;

const fallbackDescription = (() => {
  if (news.excerpt && news.excerpt.trim().length > 0) return news.excerpt;
  const plain = (news.content ?? '').replace(/<[^>]+>/g, ' ').replace(/\s+/g, ' ').trim();
  if (plain.length === 0) return 'Berita resmi dari Portal Alumni IKA UNIMED.';
  return plain.length > 160 ? plain.slice(0, 157) + '...' : plain;
})();
```

Tag `<Head>` sekarang:

- `description` = `fallbackDescription` (selalu ada, tidak pernah string kosong).
- `og:image` = `ogImageUrl` (selalu ada — fallback ke aset CTA bila berita tanpa gambar).
- Tambah `og:description`, `twitter:description` pakai `fallbackDescription`.
- Tambah `<meta property="article:published_time">`, `article:modified_time`, `article:author`, `article:section` (sesuai spec OpenGraph Article — meningkatkan kualitas share di Facebook/LinkedIn).

Schema.org `NewsArticle`:

- `description` ← `fallbackDescription`.
- `image` ← `[ogImageUrl]` (selalu ada).
- `author.name` fallback `'Redaksi IKA UNIMED'` (sebelumnya `'Admin'`).
- `publisher.logo.url` ← `${origin}/images/logo_ikaunimed.png` (sebelumnya `logo.png` yang tidak ada).

### 3. `resources/js/Pages/News/Show.tsx` — hapus duplikasi Author Box

**Sebelum:** dua kotak Author Box di artikel detail (atas: bg slate + label "Penulis Terverifikasi"; bawah: bg white + label "Ditulis Oleh").

**Sesudah:** hanya **satu** Author Box (yang label "Ditulis Oleh", styling lebih elegan). Label "Penulis Terverifikasi" — yang **misleading** karena belum ada sistem verifikasi — ikut dihapus. Avatar fallback ganti dari `'A'` ke `'R'` (Redaksi) agar konsisten dengan nama fallback.

Teks Author Box yang tersisa juga di-polish:

- "Kontributor aktif di **Portal Berita IKA UNIMED**. Menyajikan informasi terkini seputar alumni dan **Universitas Negeri Medan**." (sebelumnya: "...portal berita IKA UNIMED... kampus Universitas Negeri Medan." — kapitalisasi tidak konsisten, kata "kampus" kurang formal).

### 4. `resources/js/Pages/News/Show.tsx` — branding fallback nama penulis

`news.author?.name || 'Admin'` (di Meta Info card di atas judul) → **`news.author?.name || 'Redaksi IKA UNIMED'`** (sejajar dengan Author Box di bawah). Avatar inisial: `'A'` → `'R'`.

### 5. `resources/js/Pages/News/Show.tsx` — copy "Berita Terkait"

`Artikel lain yang mungkin kamu tertarik` → **`Artikel lain yang mungkin menarik untuk Anda baca`** (gaya bahasa formal-hangat, menyapa pembaca dengan "Anda" konsisten dengan tone portal).

### 6. `resources/views/app.blade.php` — fallback OG default

`asset('images/og-default.jpg')` → `asset('images/cta_ikaunimed-002.png')` (file yang **terbukti ada**). Mencegah 404 saat halaman lain (di luar News) di-share tanpa custom og:image.
