## Tujuan

> *Blok editorial (FlashContent, VideoPopular, KolumOpini, BeritaPopuler, TagPopuler, KomentarTerbanyak, PollingSection) bisa diisi data nyata tanpa mengubah layout.*

Cakupan:

- Identifikasi tiap blok di `News/Index.tsx` & komponen pendukungnya di `resources/js/components/`.
- Tetapkan **kontrak data minimal per blok** — bentuk prop yang stabil agar pengisian data editorial bisa bertahap tanpa revisi besar di kode.
- Tulis kontrak sebagai **single source of truth** di PHPDoc `NewsController::index` agar developer berikutnya membaca peta yang sama.
- Perbaiki **bug latent** dan **inkonsistensi** yang ditemukan saat audit.

## Perubahan yang Dieksekusi

### 1. `database/seeders/CategorySeeder.php`

**Masalah:** slug `opini`, `artikel`, dan `alumni` tidak ada di seeder, sehingga query `whereHas('categories', slug='opini')` di `KolumOpini` query selalu mengembalikan nol baris — blok di sidebar utama selalu null/hilang.

**Perbaikan:** tambah tiga kategori dengan komentar penjelas yang menjelaskan kewajibannya.

```php
[
    'name' => 'Opini',
    'slug' => 'opini',
    'description' => 'Kolom opini dan gagasan alumni IKA UNIMED',
    'icon' => '📝',
    'order' => 9,
],
[
    'name' => 'Artikel',
    'slug' => 'artikel',
    'description' => 'Artikel panjang, esai, dan liputan khusus alumni',
    'icon' => '📰',
    'order' => 10,
],
[
    'name' => 'Alumni',
    'slug' => 'alumni',
    'description' => 'Berita & kabar dari para alumni UNIMED',
    'icon' => '🎓',
    'order' => 11,
],
```

Setelah `php artisan db:seed --class=CategorySeeder --force`, ketiganya muncul di tabel `categories`.

### 2. `app/Http/Controllers/NewsController.php`

**Penambahan utama:**

- **PHPDoc kontrak data** multi-baris di atas `index()` — tabel ringkas prop → sumber → komponen FE. Developer berikutnya cukup membaca header method untuk mengerti payload halaman.
- `$opinionColumns` mapping kini menyertakan `'published_at' => $item->published_at?->toISOString()` agar komponen `KolumOpini` bisa render *relative-date* dinamis.

```php
$opinionColumns = Cache::remember('news.opinion_columns', 60 * 15, function () {
    return News::published()
        ->whereHas('categories', fn($q) => $q->where('slug', 'opini'))
        ->with(['author:id,name', 'categories:id,name,slug'])
        ->latest('published_at')
        ->take(8)
        ->get()
        ->map(fn ($item) => [
            'id' => $item->id,
            'title' => $item->title,
            'slug' => $item->slug,
            'author' => $item->author?->name,
            'category' => $item->categories->first()?->name,
            'published_at' => $item->published_at?->toISOString(),  // BARU
        ]);
});
```

### 3. `resources/js/components/KolumOpini.tsx`

**Masalah:** setiap kartu menampilkan teks **`<span>2 hari lalu</span>` hard-coded** — tidak peduli kapan berita sebenarnya dipublikasikan. Membohongi pembaca, melanggar standar konten resmi yang akan direview oleh Google AdSense.

**Perbaikan:**

- Tambah `published_at?: string | null` ke interface `OpinionColumnItem`.
- Tambah helper `formatRelativeDate(iso)` lokal yang mengembalikan:
  - `"Hari ini"` jika 0 hari.
  - `"1 hari lalu"` / `"N hari lalu"` jika < 7 hari.
  - `"M minggu lalu"` jika 7–29 hari.
  - format `id-ID` (`"25 Apr 2026"`) jika ≥ 30 hari.
  - `null` jika `iso` falsy/invalid → komponen tidak menampilkan tanggal sama sekali (BUKAN dummy "2 hari lalu").
- PHPDoc komponen menjelaskan kontrak data.

### 4. `resources/js/components/BeritaPopuler.tsx`

**Masalah:** komponen tidak punya field `image` di interface `PopularNewsItem`. Thumbnail dirender sebagai `<div className="bg-[#E6EAE8]" />` polos — kotak abu-abu kosong, padahal controller sudah mengirim `image` URL absolut hasil `News::buildImageUrl`. Akibatnya sidebar "Berita Alumni Terpopuler" terlihat lemah secara visual.

**Perbaikan:**

- Tambah `image?: string | null` dan `published_at?: string | null` ke interface.
- Render `<img src={item.image}>` ketika ada (dengan `loading="lazy"` & `decoding="async"`).
- Fallback ke ikon 📰 di lingkaran tosca-muda (`bg-[#F0FDFA]`) ketika `image` null — bukan kotak abu-abu kosong yang ambigu.
- `formatViewCount` helper kecil agar `0` tidak ditampilkan sebagai `"0.0K"` (sebelumnya: `(0/1000).toFixed(1)` = `"0.0K"` yang janggal).
- Berlaku untuk kedua varian `list` dan `grid`.

### 5. `resources/js/Pages/News/Index.tsx`

**Sinkronkan TypeScript interface dengan kontrak baru:**

```ts
interface OpinionItem {
  ...
  published_at?: string | null;  // BARU
}

interface PopularNewsItem {
  ...
  published_at?: string | null;  // diperketat (sebelumnya: string | undefined)
}
```

## Hal yang TIDAK Disentuh (Sengaja)

- **`TagPopuler` navigation**: tombol tag belum punya link karena route `tag.show` belum ada di `routes/web/public/`. Membuat route baru = mengubah arsitektur publik (di luar scope Item 4 yang fokus ke kontrak data). Akan ditangani di Item 6 (copywriting/UX) atau ketika fitur "filter berita per tag" diputuskan.
- **`SuratPembaca` & `RecommendedForYou`**: ada di barrel `editorial.ts` tapi tidak dipakai di `News/Index.tsx`. Kemungkinan dipakai di halaman lain. Tidak diaudit sekarang.
- **Logika cache TTL**: durasi cache (`60 * 30`, `60 * 15`) dipertahankan apa adanya — bukan masalah kontrak.
- **Modul Polling & Komentar (Fase 2)**: kontrak prop sudah didefinisikan di komponen (`PollData`, `DiscussionItem`); implementasi backend disengaja ditunda sampai keputusan editorial (apakah benar dibutuhkan) jelas.
