# Blueprint Implementasi Moderation & Workflow

Dokumen ini merinci rencana migrasi dan implementasi fitur Moderasi (Post Alumni, Beasiswa, Karir) dan Workflow Legalisasi ke Filament.

## 1. Konsep & Tujuan
- **Moderasi Terpusat**: Memberikan dashboard bagi admin untuk mereview dan menyetujui post dari alumni sebelum tampil di publik.
- **Workflow Legalisasi**: Menyediakan antarmuka bagi admin untuk memproses pengajuan legalisasi dokumen alumni dari status `pending` ke `completed`.

## 2. Resource yang Akan Dibangun

### A. AlumniPostResource (Moderasi Sosial)
- **Fungsi**: Review post alumni (Prestasi, Pernikahan, Wafat, Usaha).
- **Schema**:
    - Judul, Kategori, Konten (RichEditor).
    - Status: `draft`, `review`, `published`, `rejected`.
    - Note Penolakan (khusus status `rejected`).
- **Fitur**: Action "Approve" dan "Reject" langsung dari tabel.

### B. ScholarshipResource & JobVacancyResource
- **Fungsi**: Manajemen info beasiswa dan lowongan kerja.
- **Schema**:
    - Scholarship: Judul, Provider, Deadline, Link, Konten.
    - JobVacancy: Judul, Company, Location, Deadline, Konten.

### C. LegalizationResource (Workflow)
- **Fungsi**: Memproses pengajuan legalisasi.
- **Status Workflow**: `submitted` -> `verified` -> `processing` -> `completed` / `rejected`.
- **Schema**:
    - Info Alumni (Read-only).
    - Detail Pengajuan (Jenjang, Tahun Lulus, Jumlah).
    - File Pendukung (Lampiran Ijazah/Transkrip).
    - Admin Note & Status Update.

## 3. Keamanan & Akses
- **Akses**: Admin dan Editor dapat memoderasi. Writer hanya bisa melihat.
- **Authorization**: Menggunakan method `canAccessPanel` dan Policy internal.

## 4. Tahapan Kerja
1. Generate Resources: `AlumniPost`, `Scholarship`, `JobVacancy`, `Legalization`.
2. Implementasi Schema & Table untuk masing-masing resource.
3. Integrasi Workflow (Action buttons untuk update status cepat).
4. Dokumentasi di `03._migration_log.md`.
