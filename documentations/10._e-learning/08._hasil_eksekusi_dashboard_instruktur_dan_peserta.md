Ringkasan eksekusi tahap dashboard instruktur dan tampilan peserta
=================================================================

1. Endpoint dan controller baru
------------------------------

- Menambahkan `CourseDashboardController` di namespace `App\Http\Controllers\Dashboard`.
- Menambahkan method:
  - `index(Request $request)` untuk halaman “Kursus Saya” (dashboard instruktur).
  - `participants(Request $request, Course $course)` untuk halaman “Lihat Peserta” per course.
- Menambahkan route baru di `routes/web.php`:
  - `GET /dashboard/courses` → `dashboard.courses.index` → `CourseDashboardController@index`.
  - `GET /dashboard/courses/{course}/participants` → `dashboard.courses.participants` → `CourseDashboardController@participants`.

2. Logika pemilihan kursus instruktur (halaman “Kursus Saya”)
------------------------------------------------------------

- Hanya user dengan `isWriter()` (admin, editor, writer) yang boleh mengakses dashboard instruktur.
- Untuk admin dan editor:
  - Query dasar mengambil semua course.
- Untuk writer non‑admin/non‑editor:
  - Query dasar difilter `created_by = user_id` sehingga hanya melihat kursus miliknya.
- Filter yang didukung di `index()`:
  - `status` → `draft`, `published`, `archived`.
  - `category` → berdasarkan `slug` kategori.
  - `search` → berdasarkan `title` course (`like %keyword%`).

3. Statistika ringkas di dashboard instruktur
--------------------------------------------

- Menghitung daftar `course_id` yang dikelola instruktur berdasarkan query dasar.
- Menghitung metrik global:
  - `total_courses` → jumlah course yang dikelola.
  - `active_participants` → jumlah unik user (`distinct user_id`) di tabel `enrollments` dengan:
    - `course_id` berada di daftar course instruktur.
    - `status = active`.
  - `average_progress` → rata‑rata `progress_percentage` dari semua enrollment di course yang dikelola (dibulatkan ke bawah ke integer).
- Untuk setiap course di tabel:
  - `enrollments_count` → jumlah enrollment dengan `status in (active, completed)`.
  - `enrollments_avg_progress` → rata‑rata `progress_percentage` per course (via `withAvg`).

4. Halaman React baru: Dashboard/Course/Index.tsx (“Kursus Saya”)
----------------------------------------------------------------

- Lokasi: `resources/js/Pages/Dashboard/Course/Index.tsx`.
- Menggunakan layout dinamis:
  - `AdminLayout` untuk role `admin`.
  - `EditorLayout` untuk role `editor`.
  - `SubscriberLayout` sebagai fallback (misalnya writer).
- Menampilkan 3 kartu ringkasan:
  - Total kursus dikelola.
  - Jumlah peserta aktif.
  - Rata‑rata progres seluruh course.
- Menampilkan filter di atas tabel:
  - Input cari judul (`search`).
  - Select status (`Semua`, `Draft`, `Published`, `Archived`).
  - Select kategori (`Semua Kategori` atau per kategori).
- Mengirim filter melalui `router.get(route('dashboard.courses.index'), ...)` dengan `preserveState` dan `preserveScroll`.
- Tabel “Kursus Saya”:
  - Kolom:
    - `Kursus` → judul, badge level, nama kategori.
    - `Status` → badge warna berdasar status.
    - `Peserta Aktif` → membaca `enrollments_count`.
    - `Rata‑rata Progres` → bar kecil dan persentase dari `enrollments_avg_progress`.
    - `Aksi`:
      - `"Kelola Konten"` → `route('courses.show', course.slug)`.
      - `"Lihat Peserta"` → `route('dashboard.courses.participants', course.id)`.

5. Logika “Lihat Peserta” per course di controller
--------------------------------------------------

- Method `participants(Request $request, Course $course)`:
  - Menggunakan policy `CoursePolicy@manage` untuk memastikan hanya:
    - admin, editor, atau writer pemilik course yang dapat melihat peserta.
- Query enrollment:
  - `Enrollment::with('user')` dengan user fields:
    - `id`, `name`, `email`,
    - `bidang_pekerjaan`, `perusahaan`, `kota_profesional`, `status_pekerjaan`, `angkatan`,
    - `public_profile`, `profile_level`.
  - `where('course_id', $course->id)`.
- Filter:
  - `status`:
    - `active` → `where status = active`.
    - `completed` → `where status = completed`.
  - `progress`:
    - `not_started` → `progress_percentage null atau 0`.
    - `lt_25` → `1 ≤ progress_percentage < 25`.
    - `25_75` → `25 ≤ progress_percentage ≤ 75`.
    - `gt_75` → `progress_percentage > 75`.
- Sorting:
  - Default: `started_at desc`.
  - Jika `sort = progress` → urut berdasar `progress_percentage`.
  - Jika `sort = name` → join ke tabel `users` dan urut berdasar `users.name`.
- Statistika per course:
  - `total_participants` → jumlah enrollment course.
  - `completed_participants` → jumlah enrollment dengan `status = completed`.
  - `average_progress` → rata‑rata `progress_percentage` di enrollment course (dibulatkan ke bawah).

6. Halaman React baru: Dashboard/Course/Participants.tsx (“Lihat Peserta”)
-------------------------------------------------------------------------

- Lokasi: `resources/js/Pages/Dashboard/Course/Participants.tsx`.
- Layout:
  - `AdminLayout` untuk admin.
  - `EditorLayout` untuk editor.
  - `SubscriberLayout` sebagai fallback.
- Header:
  - Judul: `Peserta Kursus: [title]`.
  - Badge level dan kategori course.
  - Tombol kembali ke “Kursus Saya”.
- Kartu ringkasan:
  - Total peserta.
  - Peserta selesai.
  - Rata‑rata progres.
- Filter:
  - Status: `Semua`, `Aktif`, `Selesai`.
  - Progres: `Semua`, `Belum Mulai (0%)`, `Kurang dari 25%`, `25–75%`, `> 75%`.
  - Tombol reset filter → reset state dan reload tanpa query.
- Tabel peserta:
  - Kolom:
    - Peserta:
      - Nama, email, angkatan.
    - Status enrollment:
      - Badge `Aktif` atau `Selesai`.
    - Progres:
      - Persentase dan bar horizontal.
    - Mulai belajar:
      - Format tanggal lokal `id-ID` dari `started_at`.
    - Selesai:
      - Format tanggal dari `completed_at` atau `-`.
    - Profil profesional:
      - Kombinasi posisi, perusahaan, bidang pekerjaan, dan kota profesional.
      - Menampilkan indikator integrasi direktori:
        - Jika `public_profile = true` dan `profile_level > 0` → teks “Tampil di Direktori Alumni”.
        - Jika tidak → teks “Profil tidak dibuka di direktori”.
- Sorting di tabel:
  - Toggle pada header Progres dan Mulai:
    - Mengubah `sort` dan `direction` lalu memanggil kembali route `dashboard.courses.participants`.

7. Integrasi dengan data direktori alumni
----------------------------------------

- Dari sisi e‑learning (instruktur):
  - Halaman “Lihat Peserta” sekarang menampilkan:
    - Bidang/posisi pekerjaan melalui kombinasi:
      - `posisi_saat_ini`, `perusahaan`, `bidang_pekerjaan`.
    - Lokasi profesional (`kota_profesional`).
    - Angkatan alumni (`angkatan`).
  - Informasi ini diambil langsung dari tabel `users` dan mengikuti logika yang sama dengan direktori alumni.
  - Status “tampil di direktori” dikomunikasikan melalui teks singkat berbasis:
    - `public_profile` dan `profile_level` dari user.
- Dengan ini, instruktur memperoleh konteks latar belakang peserta tanpa menambah endpoint baru di direktori.

8. Catatan verifikasi awal
--------------------------

- Route baru:
  - `route('dashboard.courses.index')` dan `route('dashboard.courses.participants', course.id)` sudah digunakan di halaman React.
- Daftar yang perlu dicek manual lewat browser:
  - Login sebagai admin/editor/writer yang memiliki course.
  - Akses `/dashboard/courses`:
    - Pastikan daftar kursus muncul sesuai hak kelola.
    - Tombol “Lihat Peserta” mengarah ke `/dashboard/courses/{id}/participants`.
  - Di halaman peserta:
    - Pastikan filter status dan progres bekerja.
    - Pastikan informasi profesional muncul untuk peserta yang sudah melengkapi profil.
