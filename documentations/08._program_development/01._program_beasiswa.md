Sekarang Kita Punya 3 Opsi Desain
1️⃣ Minimal (Paling Aman untuk Sekarang)
Tambahkan halaman:
Dashboard → Lamaran Saya
Tampilkan:
Nama beasiswa
Status: pending / approved / rejected
Tanggal update
Tanpa email.
Tanpa notifikasi.
Hanya status viewer.
✔ Stabil
✔ Tidak kompleks
✔ Tidak mengganggu arsitektur
Ini cukup profesional.

2️⃣ Level Menengah
Tambahkan:
Halaman “Lamaran Saya”
Email otomatis saat status berubah
Contoh:
“Lamaran Anda telah diterima.”
“Lamaran Anda ditolak.”
✔ Lebih profesional
❗ Perlu setup mail & testing

3️⃣ Level Lanjut (Belum Perlu Sekarang)
In-app notification system
Bell notification
Riwayat aktivitas
Audit log publik
Ini sudah masuk sistem besar.

Rekomendasi Saya untuk Tahap Sekarang
Karena Anda sedang fokus stabilitas:
Tambahkan hanya halaman “Lamaran Saya” tanpa email dulu.
Itu cukup untuk:
Transparansi
UX yang sehat
Tidak mengubah arsitektur approval
Approval tetap di Filament.
Subscriber hanya membaca status.
