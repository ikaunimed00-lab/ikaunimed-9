# 🏗 Analogi Rumah Sederhana

Bayangkan website Anda seperti rumah:

* **Kategori** = Lemari di dalam ruangan
  (mengelompokkan isi konten: berita, artikel, pengumuman)

* **Modul Beasiswa** = Satu ruangan khusus
  (punya alur sendiri, form sendiri, database sendiri, dashboard sendiri)

Masalah Anda sekarang:
CTA masih mengira Beasiswa itu “lemari”.
Padahal Beasiswa sudah menjadi “ruangan khusus”.

# 🎯 Keputusan Arsitektur (Harus Tegas)

Kita tetapkan sekarang:

> Beasiswa adalah **modul mandiri**, bukan kategori konten.

Artinya:

* Tidak perlu `/kategori/beasiswa`
* Tidak perlu `/categories/beasiswa`
* Gunakan `/beasiswa`
* Semua alur apply, applicants, dashboard berdiri sendiri

# 🔥 Apa yang Harus Kita Lakukan?

## 1️⃣ Bersihkan Link Homepage

Semua CTA Beasiswa → arahkan ke:

```
/beasiswa
```

## 2️⃣ Tegaskan Pemisahan Konseptual

Buat aturan internal:

| Jenis    | Digunakan Untuk                                             |
| -------- | ----------------------------------------------------------- |
| Kategori | Mengelompokkan konten (News, Artikel)                       |
| Modul    | Fitur dengan sistem sendiri (Beasiswa, Event, Donasi nanti) |

## 3️⃣ Jangan Campur Lagi di Masa Depan

Kalau nanti ada:

* Event dengan sistem pendaftaran
* Donasi dengan sistem pembayaran
* Membership dengan approval

Itu semua = modul.

Bukan kategori.
