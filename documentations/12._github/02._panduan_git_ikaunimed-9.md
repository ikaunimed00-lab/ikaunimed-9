## Panduan Git untuk Project ikaunimed-9.or.id

Repository GitHub:

```text
https://github.com/ikaunimed00-lab/ikaunimed-9.git
```

### 1. Pastikan berada di folder project

```bash
cd D:\Documents\WEBSITE\ikaunimed-9.or.id
```

### 2. Cek status git dan remote

```bash
git status
git remote -v
```

Jika `origin` masih menunjuk ke repo lama (misalnya `ikaunimed-8`), hapus dulu:

```bash
git remote remove origin
```

### 3. Tambahkan remote baru khusus ikaunimed-9

```bash
git remote add origin https://github.com/ikaunimed00-lab/ikaunimed-9.git
git remote -v
```

Pastikan output sekarang menunjuk ke `ikaunimed-9.git`.

### 4. Commit perubahan lokal

Jika ada perubahan baru:

```bash
git status          # cek file yang berubah
git add .           # atau pilih file tertentu
git commit -m "Update fitur e-shop"
```

### 5. Push ke GitHub pertama kali

Jika branch utama bernama `main`:

```bash
git push -u origin main
```

Jika branch utama bernama `master`:

```bash
git push -u origin master
```

### 6. Push rutin setelah perubahan

Setiap kali selesai mengerjakan fitur/bugfix:

```bash
git status
git add .
git commit -m "Deskripsi singkat perubahan"
git push
```

### 7. Menarik perubahan dari GitHub (jika ada)

Jika ada perubahan yang dibuat di komputer lain / langsung di GitHub:

```bash
git pull
```
