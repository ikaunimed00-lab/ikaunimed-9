## Perubahan yang Dieksekusi

### 1. `app/Http/Controllers/NewsController.php` — pisahkan `editorsPicks` dari `popularNews`

**Masalah:** `EditorsPicks` di-feed `popularNews` yang sama dengan `BeritaPopuler` → 5–6 berita teratas tampil dua kali di layout halaman.

**Perbaikan:** kontrak baru.

- `popularNews` (sumber `BeritaPopuler`) tetap: `News::published()->trending()->take(10)` — **ranking otomatis** by `view_count`.
- `editorsPicks` (sumber `EditorsPicks`) BARU: berita ber-image terbaru, **EXCLUDE** id yang sudah tampil di `heroNews` & top-3 dari `popularNews`. Kontrak ini secara semantik mewakili "pilihan kurasi" — bisa kelak diganti ke flag `is_editors_pick` di tabel news tanpa mengubah props frontend.

```php
$editorsPickExcludeIds = collect($heroNews)
    ->pluck('id')
    ->merge($popularNews->take(3)->pluck('id'))
    ->unique()->values()->toArray();

$editorsPicks = Cache::remember('news.editors_picks', 60 * 30, function () use ($editorsPickExcludeIds) {
    return News::published()
        ->whereNotIn('id', $editorsPickExcludeIds)
        ->whereNotNull('image')
        ->select('id', 'title', 'slug', 'image', 'published_at')
        ->latest('published_at')
        ->take(8)
        ->get()
        ->map(fn ($n) => [
            'id' => $n->id,
            'title' => $n->title,
            'slug' => $n->slug,
            'image' => News::buildImageUrl($n->image),
            'published_at' => $n->published_at?->toISOString(),
        ]);
});
```

Cache key `news.editors_picks` ditambahkan ke daftar invalidation di `News::$booted` (`saved` & `deleted`).

### 2. `resources/js/components/EditorsPicks.tsx` — render thumbnail nyata

**Masalah:** thumbnail hanya `<div className="bg-[#E6EAE8] animate-pulse" />` — selalu placeholder, tidak pernah ada gambar.

**Perbaikan:**

- Tambah field `image` & `published_at` di interface.
- Render `<img src={pick.image} ... />` jika ada, fallback ke ikon `📰` saat null.
- Tambah helper `formatRelativeDate()` agar label "X hari lalu" jujur sesuai `published_at` (bukan hardcoded `"2 hari lalu"`).
- Tambahkan PHPDoc kontrak data di JSDoc komponen.

### 3. `resources/js/components/KomentarTerbanyak.tsx` — buang mock, kontrak jujur

**Masalah:** mock random `Math.floor(Math.random() * 200) + 10` per render.

**Perbaikan:**

- Definisi interface `DiscussionItem { id, title, slug, comments_count, last_commented_at? }`.
- Prop `items` default `[]`. Saat **kosong** → tampilkan **placeholder ramah** dengan ikon, judul "Diskusi alumni segera hadir", dan deskripsi: *"Modul komentar sedang disiapkan. Sementara, silakan jelajahi berita terbaru di kolom utama."*.
- JSDoc menyatakan kontrak Fase 2: ketika modul komentar siap, kirim items dari controller dengan bentuk yang sama.

### 4. `resources/js/components/PollingSection.tsx` — buang mock, kontrak jujur

**Masalah:** mock poll dengan suara fiktif yang ditampilkan seolah suara nyata.

**Perbaikan:**

- Interface `PollData { id, question, options[{id, label, votes}], total_votes, closes_at? }`.
- Prop `poll` default `null`. Saat **null** → tampilkan placeholder ramah: *"Polling alumni segera hadir... Pertanyaan dan pilihan jawaban akan ditampilkan di sini segera setelah dipublikasikan."*.
- Tombol vote sekarang menyimpan TODO Fase 2: panggil `POST /api/polls/{poll.id}/vote` sehingga jelas titik kerja berikutnya.

### 5. `resources/js/Pages/News/Index.tsx` — wiring kontrak baru

- Tambah interface `EditorsPickItem` (`id, title, slug, image?, published_at?`).
- Tambah prop `editorsPicks?: EditorsPickItem[]` ke `NewsIndexProps`.
- `<EditorsPicks items={editorsPicks} />` (sebelumnya `items={popularNews}`).
- `<PollingSection poll={null} />` (eksplisit menyatakan polling belum aktif).
- `<KomentarTerbanyak maxItems={5} items={[]} />` (eksplisit menyatakan komentar belum aktif).

### 6. `app/Models/News.php` — invalidation cache

Cache key `news.editors_picks` ditambahkan ke daftar `Cache::forget(...)` di event `saved` & `deleted`, sejajar dengan `news.popular_news`, `news.opinion_columns`, dst.
