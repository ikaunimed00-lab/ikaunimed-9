# 2️⃣ Struktur Query Final (Server)

Urutan logika tetap:

```php
$query = User::appearInDirectory()
    ->with('educations')
    ->latest('updated_at');
```

Kemudian tambahkan:

```php
$query->when($request->search, function ($q, $search) {
    $q->where('name', 'like', "%{$search}%");
});

$query->when($request->bidang_pekerjaan, function ($q, $bidang) {
    $q->where('bidang_pekerjaan', $bidang);
});

$query->when($request->status_pekerjaan, function ($q, $status) {
    $q->where('status_pekerjaan', $status);
});
```

Untuk angkatan:

```php
$query->when($request->angkatan, function ($q, $angkatan) {
    $q->whereHas('educations', function ($edu) use ($angkatan) {
        $edu->where('admission_year', $angkatan);
    });
});
```

Kemudian:

```php
$users = $query->paginate(12)->withQueryString();
```

✔ Tidak ada N+1
✔ Tidak ada join berat kecuali angkatan dipakai
✔ Tetap menghormati `appearInDirectory()`
